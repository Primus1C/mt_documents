Партионный учёт валюты ведётся, когда включена пометка ![ПартионныйУчет.png](/img/user/Assets/%D0%9F%D0%B0%D1%80%D1%82%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9%D0%A3%D1%87%D0%B5%D1%82.png) **«Вести партионный учет»** и в **валюте**, и в **кассе** (денежном счёте прихода или списания). На кассе дополнительно задаётся дата **«Начало партионного учета»** — до этой даты партии по кассе не формируются.

---

# Зачем это нужно

Обычный остаток по кассе показывает только сумму в валюте. Партионный учёт дополнительно хранит, **сколько базовой валюты** «лежит» в этом остатке. По соотношению суммы партии и суммы в базовой валюте получается **средневзвешенный курс** остатка на кассе.

Это нужно, чтобы:

- при списании партионной валюты уходить не «просто сумма», а доля стоимости в базовой валюте;
- видеть фактический средний курс покупки/продажи по обменным операциям за день;
- контролировать, что со счёта нельзя списать больше, чем есть в партиях.

---

# Как включить

1. В справочнике **Валюты** у нужной валюты установите **«Вести партионный учет»**.
2. В справочнике **Денежные счета (кассы)** у кассы установите ![ПартионныйУчет.png](/img/user/Assets/%D0%9F%D0%B0%D1%80%D1%82%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9%D0%A3%D1%87%D0%B5%D1%82.png) **«Вести партионный учет»** и дату **«Начало партионного учета»**.
3. Если по кассе уже есть проведённые документы, сменить признак партионного учёта нельзя — сначала разберитесь с движениями.

Партионный учёт по операции действует только если:

- у валюты включён партионный учёт;
- у кассы включён ![ПартионныйУчет.png](/img/user/Assets/%D0%9F%D0%B0%D1%80%D1%82%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9%D0%A3%D1%87%D0%B5%D1%82.png) партионный учёт;
- дата документа **не раньше** даты начала партионного учёта кассы.

---

# Что происходит в документах «Движение денег»

Учёт партий пишется при установке **«Окончательно»** (полный учёт). Движения идут в регистр **«Партии валюты»**: сумма в валюте и сумма в базовой валюте по кассе.

| Ситуация                                                                     | Что происходит                                                                                                                                          |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ввод остатков** партионной валюты на кассе с парт.учётом                   | Приход партии (стартовый остаток с курсом)                                                                                                              |
| **Обмен валюты** — покупка партионной валюты на кассу «куда» с парт.учётом   | Приход партии купленной валюты                                                                                                                          |
| **Расход** с кассы с парт.учётом (оплата, обмен и др., кроме особых случаев) | Расход партии: списывается сумма и **пропорциональная** доля в базовой валюте (средневзвешенно)                                                         |
| **Перемещение** между кассами                                                | Разрешено, только если **обе** кассы ведут ![ПартионныйУчет.png](/img/user/Assets/%D0%9F%D0%B0%D1%80%D1%82%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9%D0%A3%D1%87%D0%B5%D1%82.png) парт.учёт по этой валюте: расход с одной + приход на другую с той же долей в базовой |
| Перемещение **с кассы без парт.учёта на кассу с парт.учётом**                | **Запрещено**                                                                                                                                           |

При расходе система проверяет остаток партий: если партийной суммы недостаточно — документ не проведётся («Недостаточно денег для списания (партионный учет)…»).

---

# Средневзвешенный курс по обмену

В документе **«Движение денег»** с видом **«Обмен валюты»** есть флаг **«Рассчитывать средний курс»**.

Если флаг включён и документ **окончательный**:

- по всем окончательным обменам за этот день (по фирме) с тем же направлением (покупка / продажа) считается средний курс;
- результат записывается в регистр **«Курсы валют»** на дату:
  - **Курс закупки средний** — при покупке валюты;
  - **Курс продажи средний** — при продаже валюты.

Средний курс остатка на конкретной кассе в любой момент — это отношение сумм партии (валюта ↔ базовая) по регистру **«Партии валюты»**.

---

# Отчёты и просмотр

| Где | Что смотреть |
|---|---|
| Отчёт **«Партии валют»** | Остатки и движения партий по кассам и валютам |
| Отчёт **«Средний курс»** | Расчёт средних курсов по обменам |
| **Курсы валют** | Поля «Курс закупки средний» / «Курс продажи средний»; оттуда же можно открыть отчёт среднего курса |
| Список **«Движения денег»** (при отборе по кассе с парт.учётом) | Команда отчёта по партиям валюты |

---

# На что обратить внимание

1. Нужны **оба** признака ![ПартионныйУчет.png](/img/user/Assets/%D0%9F%D0%B0%D1%80%D1%82%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9%D0%A3%D1%87%D0%B5%D1%82.png): в валюте и в кассе; плюс дата начала на кассе.  
2. Полный учёт партий — только после **«Окончательно»** в движении денег.  
3. Нельзя «завезти» партионную валюту перемещением с обычной кассы на кассу с парт.учётом.  
4. Списание контролируется по партиям жёстче, чем обычный остаток кассы.  
5. Средний курс в справочнике курсов обновляется обменами с флагом **«Рассчитывать средний курс»**, а не каждым движением подряд.
