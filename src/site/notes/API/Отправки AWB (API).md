# StockAPI — Отправки AWB (`/awbshipment`)

HTTP-сервис **StockAPI**: чтение проведённых документов `ОтправкаAWB`.

---

## Авторизация

```
X-Api-Key: <токен учётной записи интеграции>
```

Неактивная или неизвестная учётная запись → **401**.

Тело ответа — **JSON**, UTF-8. Даты в параметрах запроса: `yyyy-MM-dd`. В ответе: `date` отправки и `supplierDate` — `yyyy-MM-ddTHH:mm:ss`, `date` инвойса — `yyyy-MM-dd`.

---

## Эндпоинты

| Метод | URL | Назначение |
|-------|-----|------------|
| GET | `/awbshipment` | Список проведённых отправок AWB за интервал дат |

Базовый путь: `/trade/hs/stock/awbshipment`.

---

## Пагинация (GET `/awbshipment`)

| Параметр | Синоним | Описание |
|----------|---------|----------|
| `page` | — | Номер страницы, с 1 (по умолчанию 1) |
| `pageSize` | `limit` | Размер страницы, 1–500 (по умолчанию 500) |

Ответ всегда содержит: `page`, `pageSize`, `totalItems`, `totalPages`, `items[]`. Страница считается по документам `ОтправкаAWB`.

Неверный `page` / `pageSize` → **400**.

---

## GET `/awbshipment`

**Назначение:** получить проведённые документы `ОтправкаAWB`, дата которых попадает в интервал `dateFrom`…`dateTo` (без времени, включительно).

**Запрос:**  
`GET /trade/hs/stock/awbshipment?...`

```
GET /awbshipment?dateFrom=2026-08-01&dateTo=2026-08-31
GET /awbshipment?from=2026-08-01&to=2026-08-31
GET /awbshipment?dateFrom=2026-08-01&dateTo=2026-08-31&page=1&pageSize=50
```

| Параметр | Синонимы | Описание |
|----------|----------|----------|
| `dateFrom` | `from` | Начало периода по дате документа (`yyyy-MM-dd`) |
| `dateTo` | `to` | Конец периода по дате документа (`yyyy-MM-dd`) |
| `page` | — | Номер страницы (см. пагинацию) |
| `pageSize` | `limit` | Размер страницы (см. пагинацию) |

`dateFrom` и `dateTo` **обязательны**. Неверный формат, отсутствие границы или `dateFrom` позже `dateTo` → **400**.

### Поля отправки (`items[]`)

| Поле | Источник (1С) | Описание |
|------|---------------|----------|
| `number` | `ОтправкаAWB.Номер` | Номер документа |
| `date` | `ОтправкаAWB.Дата` | Дата документа (`yyyy-MM-ddTHH:mm:ss`) |
| `awb` | `ОтправкаAWB.AWB` | Номер AWB |
| `invoices` | ТЧ `Инвойсы` | Строки инвойсов отправки |

### Поля элемента `invoices[]`

| Поле | Источник (1С) | Описание |
|------|---------------|----------|
| `number` | `_Инвойс.Номер` | Номер инвойса в 1С |
| `date` | `_Инвойс.Дата` | Дата документа (`yyyy-MM-dd`) |
| `supplierNumber` | `_Инвойс.ВКД_НомерИнвойсаПоставщика` | Номер инвойса поставщика |
| `supplierDate` | `_Инвойс.ВКД_ДатаИнвойсаПоставщика` | Дата инвойса поставщика (`yyyy-MM-ddTHH:mm:ss`) |
| `seller` | `_Инвойс.Контрагент` | Наименование поставщика |
| `sellerCode` | `_Инвойс.Контрагент.Код` | Код поставщика |
| `numberOfDeliveries` | `_Инвойс.КоличествоПоставок` | Количество поставок в инвойсе |
| `delivery` | `ОтправкаAWB.Инвойсы.Поставка` | Номер поставки в строке отправки; `0` — не заполнена |
| `invoiceStatus` | регистр `СостоянияИнвойсов` | Статус инвойса на английском |
| `items` | ТЧ `_Инвойс.Поставки` | Товары поставки (см. ниже) |

`invoiceStatus`:

| Значение | Статус в 1С |
|----------|-------------|
| `Not shipped` | Не отправлен |
| `In transit` | В пути |
| `Partially received` | Частично прибыл |
| `Received` | Прибыл |
| `""` | Статус не задан |

### Массив `invoices[].items[]`

Структура элемента **как у `GET /invoices`**: `item`, `itemCode`, `itemSku`, `qty`, `price`, `amount`.

Заполняется **только если в строке ТЧ отправки заполнена поставка** (`delivery` > 0). Тогда в массив попадают строки ТЧ `Инвойс.Поставки` с тем же номером поставки:

| Поле | Источник (1С) | Описание |
|------|---------------|----------|
| `item` | `Номенклатура` | Наименование |
| `itemCode` | `Номенклатура.Код` | Код |
| `itemSku` | `Номенклатура.SKU` | SKU |
| `qty` | `Поставки.Количество` | Количество в поставке |
| `price` | `ВКД_Товары.ЦенаИнвойса` (если 0 — `Поставки.Цена`) | Цена в валюте инвойса |
| `amount` | `price * qty` (если цена 0 — `Поставки.Сумма`) | Сумма |

Если поставка в строке отправки не заполнена (`delivery` = 0) — `items` всегда пустой массив, даже если в инвойсе есть товары.

### Ошибки GET

| HTTP | Когда |
|------|--------|
| **401** | Нет / неверный `X-Api-Key` |
| **400** | Нет `dateFrom`/`dateTo`, неверный формат, `dateFrom` позже `dateTo`; некорректные `page` / `pageSize` |
| **500** | Непредвиденная ошибка сервера |

```json
{
  "error": "Текст ошибки"
}
```
