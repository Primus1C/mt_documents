# GET `/api/v1/counterparties`

**Описание:** 
    получение контрагентов, доступных учетной записи
**Запрос**
    GET /trade/hs/stock/counterparties
**Параметры:** 
    
| параметр                                 | описание                                                                                                   | обязательный                                        |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| search                                   | наименование заказчика (поиск происходит по вхождению этого параметра запроса в наименования контрагентов) | необязателен, если указан *код заказчика*           |
| counterpartyCode \| customerCode \| code | код заказчика                                                                                              | необязателен, если указано *наименование заказчика* |
**Примеры:** 
    GET /trade/hs/stock/counterparties?page=1&pageSize=50

# GET `/api/v1/counterpartiesGroups`

**Описание:**  
    получение групп контрагентов (родительских папок), доступных учётной записи интеграции. Список используется для выбора параметра `groupCode` при создании контрагента (`POST /counterparties`).

**Запрос**  
    GET /trade/hs/stock/counterpartiesGroups

**Параметры:**  
    нет (авторизация — заголовок `X-Api-Key`, как у остальных методов Stock API)

**Поведение:**

| учётная запись | что возвращается |
| --- | --- |
| обычная | группы из ТЧ «Контрагенты» текущей учётной записи |
| администратор API | все уникальные группы из ТЧ «Контрагенты» всех **активных** учётных записей |

**Пример:**  
    GET /trade/hs/stock/counterpartiesGroups

**Ответ**
```json
{
    "items": [
        {
            "group": "Покуптели менеджера Петрова",
            "groupCode": "937"
        },
        {
            "group": "Покупатели Восток",
            "groupCode": "456"
        }
    ]
}
```

> [!warning]
> Параметр `groupCode` обязателен при создании контрагента (`POST /counterparties`). Код группы должен быть из списка, возвращаемого этим методом.

# POST `/api/v1/counterparties`

**Описание:**  
    создание контрагентов заказов
**Запрос**
    POST /trade/hs/stock/counterparties
**Параметры:**

| параметр                         | описание                                                                                             | обязательный        |
| -------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------- |
| counterparty \| name \| customer | наименование контрагента                                                                             | +                   |
| email                            | Email                                                                                                | -                   |
| phone \| phones                  | телефон(ы)                                                                                           | -                   |
| city                             | город (заполняется только из уже существующих в 1С)                                                  | -                   |
| note \| comment                  | комментарий                                                                                          | -                   |
| groupCode                        | код группы-родителя (папки); см. `GET /counterpartiesGroups`                                         | +                   |
| currency                         | Наименование [[Справочники (НСИ)/Виды цен\|валюты]], строка, по которой определяется Вид цены, назначаемый контрагенту | - (рекомендуется +) |

> [!warning] 
> Если [[Справочники (НСИ)/Виды цен\|вид цены]] не задан при создании клиента, регистрация его заказов (через API) будет невозможна, пока вид цены не будет установлен пользователем в 1С (метода API для изменения контрагентов пока нет) 

**Ошибки `groupCode` (HTTP 400):**

| ситуация                    | `error`                                                       |
| --------------------------- | ------------------------------------------------------------- |
| не указан                   | `Укажите groupCode — код группы контрагентов (родителя).`     |
| не число                    | `Значение groupCode не числовое: '...'`                       |
| код не из ТЧ учётной записи | `Группа с кодом N недоступна для учётной записи.`             |
| в учётной записи нет групп  | `В учётной записи интеграции не указаны группы контрагентов.` |
  
**Пример запроса:**
```http
POST /trade/hs/stock/counterparties
Content-Type: application/json
{
  "counterparty": "Иванов Полуэкт",
  "groupCode": "123",
  "email": "buyer@example.com",
  "phone": "+7 999 000-00-00",
  "city": "Москва",
  "address": "ул. Примерная, 1",
  "priceType": "В местной валюте склада"
}
```

**Ответ**
```json
{
    "success": true,
    "error": "",
    "counterparty": "Иванов Полуэкт",
    "counterpartyCode": "5323"
}
```
