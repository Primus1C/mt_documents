# StockAPI — Инвойс закупки (`/invoices`)

HTTP-сервис **StockAPI**: создание и замена инвойсов закупки (документ `_Инвойс`, eng. *Purchase invoice*).

---

## Авторизация

```
X-Api-Key: <токен учётной записи интеграции>
```

Неактивная или неизвестная учётная запись → **401**.

Ограничения учётной записи:
- **поставщики** — иерархии групп из ТЧ «Поставщики» (см. `GET /sellers`).

Склады **не** используются.

Тело запроса и ответа — **JSON**, UTF-8. Даты: `yyyy-MM-dd` (в ответе — `yyyy-MM-ddTHH:mm:ss`).

---

## POST `/invoices`

**Назначение:** создать инвойс или полностью заменить существующий (upsert) и провести документ.

**Запрос:**  
`POST /trade/hs/stock/invoices`

### Ключ upsert

Существующий документ ищется по паре:

- поставщик (`sellerCode` / `alias`);
- номер инвойса поставщика (`supplierNumber` → `ВКД_НомерИнвойсаПоставщика`).

| Ситуация | Поведение |
|----------|-----------|
| Не найден | Создаётся новый `_Инвойс`, проводится |
| Найден, **нет** приходных по `ВКД_Инвойс` | Полная перезапись шапки и ТЧ `ВКД_Товары`, проведение (`replaced: true`) |
| Найден, есть приходная (в т.ч. проведённая) | **400**, замена запрещена |

### Поля заголовка

| Поле JSON | Синонимы | Обязательный | Описание |
|-----------|----------|--------------|----------|
| `sellerCode` | `supplierCode`, `code` | да\* | Код поставщика (`Контрагенты.Код`) |
| `alias` | `seller`, `supplier` | да\* | Псевдоним или наименование поставщика |
| `currency` | | да | Код валюты (`Валюты.Код` или `КодISO`) |
| `supplierNumber` | `supplierNo`, `invoiceNumber`, `invoiceNo` | да | Номер инвойса поставщика |
| `supplierDate` | `invoiceDate` | да | Дата инвойса поставщика (`yyyy-MM-dd`) |
| `date` | | нет | Дата документа; по умолчанию — текущая дата сеанса |
| `note` | `comment` | нет | Примечание (до 200 символов) |
| `items` | | да | Массив позиций |

\* Нужен хотя бы один идентификатор поставщика (`sellerCode` / `alias` и синонимы).

### Позиции `items[]`

Серии **не** поддерживаются.

| Поле | Синонимы | Обязательный | Описание |
|------|----------|--------------|----------|
| `itemCode` | `code` | да\* | Код номенклатуры |
| `itemSku` | `sku`, `SKU` | да\* | SKU |
| `itemUpc` | `upc`, `UPC` | да\* | UPC |
| `itemJan` | `jan`, `JAN`, `jan13`, `JAN13` | да\* | JAN13 |
| `item` | `name` | да\* | Наименование (точное / неточное) |
| `qty` | `quantity`, `count` | да | Количество (> 0) |
| `price` | `purchasePrice` | да\*\* | Цена в валюте инвойса |
| `amount` | `sum`, `purchaseAmount` | да\*\* | Сумма в валюте инвойса |

\* Нужен хотя бы один способ найти номенклатуру.  
\*\* Нужны `price` и/или `amount`. Если задано только одно — второе считается из `qty`.

Тип номенклатуры — только «Товар».

### Пример запроса

```json
{
  "sellerCode": "1201",
  "currency": "USD",
  "supplierNumber": "INV-7788",
  "supplierDate": "2026-08-25",
  "note": "API invoice",
  "items": [
    {
      "itemCode": "10045",
      "qty": 2,
      "price": 350.5
    },
    {
      "itemSku": "CABLE-USBC",
      "qty": 5,
      "amount": 60
    }
  ]
}
```

### Успешный ответ (200)

```json
{
  "success": true,
  "error": "",
  "number": "000001234",
  "date": "2026-08-25T15:40:00",
  "seller": "Supplier Ltd",
  "sellerCode": "1201",
  "currency": "USD",
  "supplierNumber": "INV-7788",
  "supplierDate": "2026-08-25T00:00:00",
  "posted": true,
  "amount": 761,
  "replaced": false,
  "items": [
    {
      "item": "iPhone 15",
      "itemCode": "10045",
      "itemSku": "",
      "qty": 2,
      "price": 350.5,
      "amount": 701
    },
    {
      "item": "Cable USB-C",
      "itemCode": "20010",
      "itemSku": "CABLE-USBC",
      "qty": 5,
      "price": 12,
      "amount": 60
    }
  ]
}
```

| Поле | Описание |
|------|----------|
| `replaced` | `true`, если выполнен upsert существующего инвойса |
| `amount` | Сумма документа (`Сумма`, в валюте учёта закупки с учётом курса) |
| `price` в `items` | `ЦенаИнвойса` (валюта инвойса) |

### Ошибки

| HTTP | Когда |
|------|--------|
| **401** | Нет / неверный `X-Api-Key` |
| **400** | Ошибка валидации; поставщик/товар/валюта не найдены; есть приходная по инвойсу; сбой проведения |
| **500** | Непредвиденная ошибка сервера |

```json
{
  "success": false,
  "error": "Текст ошибки"
}
```

При блокировке замены из‑за приходной в теле дополнительно могут быть заполнены реквизиты найденного инвойса (`number`, `date`, `items` и т.д.).

### Поведение в 1С

1. Создаётся или открывается `Инвойс`.
2. При замене: отмена проведения (если был проведён), очистка `Товары` и `Поставки`, перезапись шапки и строк.
3. Цены запроса — в валюте инвойса (`ЦенаИнвойса`); `ЦенаЗакупки` / `СуммаЗакупки` пересчитываются по курсу на дату документа (для базовой валюты курс = 1).
4. Документ **проводится**.
