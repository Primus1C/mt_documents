# StockAPI — остатки без цен (`/leftover`, `leftoverGET`)

HTTP-сервис **StockAPI**: выборка **остатков товаров** по регистру `ОстаткиТовара` и **резервов** по `РезервыТовара` **без** видов цен, валют и цен продажи. Обработчик HTTP-метода: **`leftoverGET`**.

Для остатков **с ценами** используйте **`GET /balances`**.

---

## Авторизация

```
X-Api-Key: <токен учётной записи интеграции>
```

Неактивная или неизвестная учётная запись → **401** (`{"error": "…"}`).

Ограничения учётной записи:
- **склады** — ТЧ «Склады» справочника `УчетныеЗаписиИнтеграции` (для роли администратора API — склады из общего списка конфигурации);
- без параметра склада в запросе возвращаются остатки по **всем разрешённым** складам учётной записи.

Тело ответа — **JSON**, UTF-8. Числовые поля `balance` и `reserve` в JSON передаются **строками** (как в других методах StockAPI).

---

## Эндпоинт

| Метод | URL | Обработчик | Назначение |
|-------|-----|------------|------------|
| GET | `/leftover` | `leftoverGET` | Остатки и резервы без цен |

Пример полного пути публикации:

```
GET /trade/hs/stock/leftover?...
```

---

## Пагинация

| Параметр | Синоним | Описание |
|----------|---------|----------|
| `page` | — | Номер страницы, с **1** (по умолчанию **1**; значение **0** трактуется как 1) |
| `pageSize` | `limit` | Размер страницы, **1–500** (по умолчанию **500**) |

Некорректные значения → **400** (`{"error": "…"}`).

Ответ всегда содержит: `page`, `pageSize`, `totalItems`, `totalPages`, `items[]`.

`totalItems` — число строк в полной выборке **до** постраничного среза (каждая строка — пара **склад + номенклатура** с положительным остатком). Сортировка: склад, затем номенклатура.

---

## GET `/leftover` (`leftoverGET`)

**Назначение:** получить список позиций с ненулевым остатком на доступных складах, с полями номенклатуры и резерва, **без** блока цен.

**Источник данных:**
- остаток — `РегистрНакопления.ОстаткиТовара.Остатки` (только `Остаток > 0`);
- резерв — `РегистрНакопления.РезервыТовара.Остатки` (сумма по складу и номенклатуре).

**Отбор номенклатуры (всегда):**
- тип **Товар**;
- не установлен **Запрет отгрузки**;
- не помечена на удаление (при фильтре по кодам).

### Параметры запроса

#### Склад (опционально)

Если параметр не указан — все склады учётной записи. Указан несуществующий или недоступный склад → **400** (`Нет доступа к указанному складу.`).

| Параметр | Синонимы | Описание |
|----------|----------|----------|
| `warehouseId` | `warehouseCode` | Числовой **код** склада |
| `code` | — | То же: числовой код склада (если не используется для других целей в этом запросе) |
| `warehouse` | — | Точное **наименование** склада |

Примеры:

```
GET /leftover?warehouseCode=1&page=1&pageSize=100
GET /leftover?warehouse=Main
```

#### Номенклатура (опционально)

| Параметр | Синонимы | Описание |
|----------|----------|----------|
| `itemCode` | — | Один числовой код номенклатуры |
| `itemCodes` | — | Несколько кодов через **запятую** |
| `item` | — | Точное **наименование** элемента (не группы) |

Неверный формат кода, несуществующий код или наименование → **400**.

```
GET /leftover?itemCode=100500
GET /leftover?itemCodes=100500,100501
GET /leftover?item=Apple iPhone 15 128GB Black
```

#### Бренд (опционально)

| Параметр | Описание |
|----------|----------|
| `brand` | Код или наименование **группы бренда** (первый уровень иерархии номенклатуры) |

Ошибка поиска бренда → **400**.

```
GET /leftover?brand=Apple
```

### Пример ответа **200**

```json
{
  "page": 1,
  "pageSize": 500,
  "totalItems": 2,
  "totalPages": 1,
  "items": [
    {
      "warehouse": "1",
      "item": "Apple iPhone 15 128GB Black",
      "itemCode": "100500",
      "brand": "Apple",
      "brandCode": "10",
      "itemSku": "SKU-001",
      "manufacturer": "Apple Inc.",
      "balance": "5",
      "reserve": "1"
    }
  ]
}
```

### Поля элемента `items[]`

| Поле | Описание |
|------|----------|
| `warehouse` | Код склада (строка) |
| `item` | Наименование номенклатуры |
| `itemCode` | Код номенклатуры (строка) |
| `brand` | Наименование бренда (группа в иерархии) |
| `brandCode` | Код группы бренда (строка) |
| `itemSku` | Реквизит SKU |
| `manufacturer` | Производитель (наименование) |
| `balance` | Остаток на складе (строка) |
| `reserve` | Резерв на складе (строка) |

Доступный для отгрузки остаток на стороне клиента: `balance − reserve` (при необходимости — с учётом вашей бизнес-логики).

---

## Коды ответов

| Код | Когда |
|-----|--------|
| **200** | Успешная выборка (в т.ч. пустой `items[]`) |
| **400** | Ошибка параметров (пагинация, склад, коды, `item`, `brand`) |
| **401** | Неверный или неактивный API-ключ |
| **500** | Необработанная ошибка на сервере (`{"error": "…"}`) |

---

## Связь с `GET /balances`

| | `GET /leftover` (`leftoverGET`) | `GET /balances` |
|---|--------------------------------|-----------------|
| Цены, виды цен, валюты | нет | да (при указании параметров цен) |
| Фильтры склад / коды / item / brand | те же имена параметров | те же |
| Пагинация | `page`, `pageSize` / `limit` | те же |

Используйте **`leftoverGET`**, когда нужны только остатки и резервы без нагрузки запросов к ценам (например, синхронизация наличия, контроль нулевых остатков без обнуления цен через отдельные процессы).

## Роли

Доступ к методу `HTTPService.StockAPI.URLTemplate.ШаблонURL_ОстаткиБезЦен.Method.leftoverGET` выдан ролям **`api_client`** и **`api_web_admin`**.
