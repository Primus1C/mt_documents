# GET `/api/v1/currencies`

**Описание:** 

Список валют из справочника `Валюты` (без помеченных на удаление). Авторизация — `X-Api-Key`. Пагинации нет: ответ — JSON-массив.

**Параметры (опционально):**

|параметр|что делает|
|---|---|
|`search`|поиск по наименованию|
|`currencyCode` / `code`|отбор по числовому `КодISO`|

**Поля элемента:**

| поле           | источник (1С)  | смысл                                                           |
| -------------- | -------------- | --------------------------------------------------------------- |
| `currencyCode` | `КодISO`       | числовой ISO-код                                                |
| `currency`     | `Наименование` | название                                                        |
| `name`         | `Код`          | буквенный код (`USD`) — его передавать в `currency` заказов/цен |
| `sign`         | `Символ`       | символ                                                          |

**Запрос:**
    GET /trade/hs/stock/currencies

**Ответ 200**
```json
[
  {
        "currencyCode": "36",
        "currency": "Австралийский доллар",
        "name": "AUD",
        "sign": "A$"
  },
  {
        "currencyCode": "840",
        "currency": "Доллар США",
        "name": "USD",
        "sign": "$"
  },
  {
        "currencyCode": "643",
        "currency": "Рубль",
        "name": "РУБ",
        "sign": "₽"
  }
]
```
