# StockAPI — Ассортимент (`/goods`)

HTTP-сервис **StockAPI**: получение списка товаров (ассортимент) с остатками на складах учётной записи за указанный период.

В учёте 1С это элементы справочника `Номенклатура` (тип «Товар»), у которых за период были остатки или движения на складах учётной записи.

---

## Авторизация

```
X-Api-Key: <токен учётной записи интеграции>
```

Неактивная или неизвестная учётная запись → **401**.

Ограничения учётной записи:
- **склады** — ТЧ «Склады» (для администратора API — склады всех активных учётных записей).

Тело ответа — **JSON**, UTF-8.

---

## GET `/goods`

**Назначение:** вернуть товары, по которым на складах учётной записи за последние N месяцев были остатки или движения.

**Запрос:**  
`GET /trade/hs/stock/goods`

### Параметры query

| Параметр | Синонимы | Обязательный | Описание |
|----------|----------|--------------|----------|
| `months` | `monthsCount` | нет | Число месяцев назад от текущей даты (целое, 1…120). По умолчанию **12** |
| `warehouseCode` | `warehouseId`, `code` | нет | Код склада: ограничить выборку одним складом из доступных учётной записи. Без параметра — все склады учётной записи |
| `page` | — | нет | Номер страницы, с 1 (по умолчанию **1**) |
| `pageSize` | `limit` | нет | Размер страницы, 1…500 (по умолчанию **500**) |

### Критерии отбора номенклатуры

В ответ попадают только элементы, для которых одновременно:

1. тип номенклатуры = **Товар**;
2. не группа и не помечена на удаление;
3. на выбранных складах за период `[сегодня − months … сегодня]` в регистре `ОстаткиТовара` было хотя бы одно из:
   - ненулевой остаток на начало периода;
   - любое движение за период;
   - ненулевой текущий остаток.

### Пример запроса

```
GET /trade/hs/stock/goods
GET /trade/hs/stock/goods?months=6
GET /trade/hs/stock/goods?months=3&warehouseCode=1
GET /trade/hs/stock/goods?page=2&pageSize=100
```

### Поля ответа

| Поле | Тип | Описание |
|------|-----|----------|
| `page` | число | Номер текущей страницы |
| `pageSize` | число | Размер страницы |
| `totalItems` | число | Всего позиций (до пагинации) |
| `totalPages` | число | Всего страниц |
| `months` | число | Фактически использованный период в месяцах |
| `items` | массив | Список товаров на текущей странице |

#### Элемент `items[]`

| Поле | Тип | Описание в 1С |
|------|-----|----------------|
| `itemCode` | строка | `Номенклатура.Код` |
| `item` | строка | `Номенклатура.Наименование` |
| `manufacturer` | строка | `Производитель.Наименование` |

Сортировка: по наименованию номенклатуры.

### Ошибки

| HTTP | Когда |
|------|--------|
| **401** | Нет / неверный `X-Api-Key` |
| **400** | Некорректный `months` / пагинация; склад недоступен; у учётной записи не заданы склады |
| **500** | Непредвиденная ошибка сервера |

Тело ошибки:

```json
{
  "error": "Текст ошибки"
}
```

Примеры текстов **400**:
- `Параметр months должен быть целым числом.`
- `Параметр months должен быть от 1 до 120.`
- `Параметр page должен быть целым числом >= 1.`
- `Параметр pageSize (или limit) должен быть целым числом от 1 до 500.`
- `pageSize не может превышать 500.`
- `Нет доступа к указанному складу.`
- `Для учётной записи не заданы склады.`
- `Параметр warehouseId (или warehouseCode) должен быть числовым кодом склада.`
