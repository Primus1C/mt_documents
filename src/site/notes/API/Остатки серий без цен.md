# StockAPI — остатки серий без цен (`/leftoverSeries`, `leftoverSeriesGET`)

HTTP-сервис **StockAPI**: серии товаров на складе по регистру **`ОстаткиТовара`** (измерение **`Партия`**, реквизит **`Партии.Серия`**) **без** видов цен, валют и цен. Обработчик: **`leftoverSeriesGET`**.

Учитываются только позиции с **учётом по сериям** (`УчетПоСериям`) и остатком **≥ 1**. Несерийная номенклатура не возвращается.

Сводные остатки без серий и без цен — **`GET /leftover`** ([Остатки без цен](Остатки%20без%20цен.md)). Остатки с ценами — **`GET /balances`**.

---

## Авторизация

```
X-Api-Key: <токен учётной записи интеграции>
```

Неактивная или неизвестная учётная запись → **401** (`{"error": "…"}`).

Ограничения учётной записи:
- **склады** — ТЧ «Склады» справочника `УчетныеЗаписиИнтеграции` (для администратора API — склады из общего списка конфигурации);
- в этом методе **склад в запросе обязателен**; недоступный склад → **400**.

Тело ответа — **JSON**, UTF-8.

---

## Эндпоинт

| Метод | URL | Обработчик | Назначение |
|-------|-----|------------|------------|
| GET | `/leftoverSeries` | `leftoverSeriesGET` | Серии серийных товаров на остатках склада |

Пример полного пути публикации:

```
GET /trade/hs/stock/leftoverSeries?warehouseCode=1
```

## GET `/leftoverSeries` (`leftoverSeriesGET`)

### Параметры запроса

#### Склад (обязательно)

| Параметр | Синонимы | Описание |
|----------|----------|----------|
| `warehouseId` | `warehouseCode` | Числовой **код** склада |
| `code` | — | Числовой код склада (если в запросе не используется для других целей) |
| `warehouse` | — | Точное **наименование** склада |

Достаточно одного способа указать склад. Склад не указан → **400**. Нет доступа или склад не найден → **400**.

Примеры:

```
GET /leftoverSeries?warehouseCode=1
GET /leftoverSeries?warehouseId=1
GET /leftoverSeries?warehouse=Main
```

#### Группировка (опционально)

| Параметр | Описание |
|----------|----------|
| `grouped` | **`true`** — серии сгруппированы по товару; **`false`** или параметр не передан — плоский список «товар + серия» |

Допустимые значения: `true`, `false`, `1`, `0`, `yes`, `no`. Иное значение → **400**.

```
GET /leftoverSeries?warehouseCode=1&grouped=true
```

#### Поиск по сериям (опционально)

| Параметр | Описание |
|----------|----------|
| `search` | Список серий для отбора: **через запятую** в одном параметре URL (аналог массива). Точное совпадение с `Партии.Серия` на остатке склада |

Если параметр **не передан** или после разбора список пуст (например, `search=,,`) — возвращаются **все** серии серийных товаров на остатке, как без фильтра.

Серии, которых **нет** на остатке указанного склада, в ответ **не попадают** (ошибки нет, просто отсутствуют в `items`).

```
GET /leftoverSeries?warehouseCode=1&search=ABC123,DEF456
GET /leftoverSeries?warehouseCode=1&search=ABC123&grouped=true
```

---

## Ответ **200**

| Поле | Описание |
|------|----------|
| `warehouse` | Код склада (строка) |
| `grouped` | Признак группировки, как в запросе |
| `items` | Массив элементов (формат зависит от `grouped`) |

### `grouped=false` (по умолчанию)

Каждый элемент — одна серия на товаре:

| Поле | Описание |
|------|----------|
| `item` | Наименование номенклатуры |
| `itemCode` | Код номенклатуры (строка) |
| `serial` | Серия (`Партии.Серия`) |

```json
{
  "warehouse": "1",
  "grouped": false,
  "items": [
    {
      "item": "Apple iPhone 15 128GB Black",
      "itemCode": "100500",
      "serial": "ABC123"
    }
  ]
}
```

### `grouped=true`

Каждый элемент — товар и массив серий на остатке:

| Поле | Описание |
|------|----------|
| `item` | Наименование номенклатуры |
| `itemCode` | Код номенклатуры (строка) |
| `serials` | Массив строк — серии без дубликатов, порядок как в выборке |

```json
{
  "warehouse": "1",
  "grouped": true,
  "items": [
    {
      "item": "Apple iPhone 15 128GB Black",
      "itemCode": "100500",
      "serials": ["ABC123", "DEF456"]
    }
  ]
}
```

Пустой остаток серийных позиций на складе → **200** с `"items": []`.

---

## Коды ответов

| Код | Когда |
|-----|--------|
| **200** | Успешная выборка |
| **400** | Не указан склад, нет доступа к складу, неоднозначный склад, неверный `grouped` |
| **401** | Неверный или неактивный API-ключ |
| **500** | Необработанная ошибка (`{"error": "…"}`) |

## Связь с другими методами

| Метод | Назначение |
|-------|------------|
| **`GET /leftover`** | Остатки и резервы по номенклатуре без цен (склад опционален, серии не детализируются) |
| **`GET /series`** | Серии на складе заказа **для номенклатуры конкретного** `ИнвойсПродажи` |
| **`GET /leftoverSeries`** | Все серии **всех серийных** товаров на остатке **указанного** склада |
