# POST `/api/v1/prices`

**Описание:**  
    создание и проведение документа [[УстановкаЦен\|Установка цен]] — запись цен продажи в регистр `ЦеныПродажи` для выбранных склада, вида цены и валюты. Документу заполняется `УчетнаяЗапись` текущей учётной записи API.

**Запрос**  
    POST /trade/hs/stock/prices

**Авторизация:**  
    заголовок `X-Api-Key` (токен [[Справочники (НСИ)/Учетные записи интеграции\|учётной записи интеграции]]).

**Тело запроса (JSON):**

| поле                                          | обяз. | описание                                                                                                     |
| --------------------------------------------- | ----- | ------------------------------------------------------------------------------------------------------------ |
| `priceType`                                   | да    | Наименование вида цены (`Справочник.ВидыЦен`)                                                                |
| `currency`                                    | да    | [[API/Валюты\|Валюта]]: буквенный код (`Код`, приоритет) или числовой ISO (`КодISO`)                             |
| `warehouse` / `warehouseCode` / `warehouseId` | да    | Склад из списка, доступного [[Справочники (НСИ)/Учетные записи интеграции\|учётной записи]]                                    |
| `items`                                       | да*   | Массив позиций с ценами (см. ниже)                                                                           |
| `salesBan`                                    | нет   | Значение по умолчанию для позиций без своего `salesBan`. `true` — запрет продажи (`РазрешитьПродажу = Ложь`) |
| `employeeCode` / `employeePin`                | усл.  | Оператор склада; обязателен, если для метода `pricePOST` включена идентификация сотрудника в учётной записи  |

\* Допустимы альтернативные имена массива: `items`, `prices`, `data`. Если массива нет, но в корне есть `itemCode` — тело трактуется как одна позиция.

**Элемент `items[]`:**

| поле       | обяз. | описание                                                                                                                                                                |
| ---------- | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `itemCode` | да    | Код номенклатуры                                                                                                                                                        |
| `price`    | да    | Массив порогов цен (см. ниже)                                                                                                                                           |
| `salesBan` | нет   | Запрет продажи **для этой номенклатуры** (склад + вид цены + валюта из корня). Приоритет над корневым `salesBan`. Без поля — берётся корень, иначе продажа разрешена \| |

**Элемент `price[]` (пороги количества):**

| поле | обяз. | описание |
| --- | --- | --- |
| `qty` | да | Порог количества. `0` — базовая цена (`Цена0`). Иначе — очередной порог `Порог1`/`Цена1` … `Порог3`/`Цена3` |
| `priceQty` | да | Цена при достижении порога |

Порядок элементов в `price[]` важен: первый с `qty = 0` задаёт базовую цену; следующие ненулевые `qty` заполняют пороги по порядку (не более **трёх** порогов помимо базовой). Формат совместим с массивом `price[]` в ответе **GET /balances**.

**Поведение:**

- создаётся проведённый документ `УстановкаЦен` на текущую дату сеанса;
- склад проверяется по доступным складам [[Справочники (НСИ)/Учетные записи интеграции\|учётной записи]];
- в шапке документа: склад, учётная запись, примечание `Создано StockAPI (…)`;
- в ТЧ «Виды цен» — пара `priceType` + `currency`;
- каждая позиция `items` → строка ТЧ «Товары» с тем же видом цены и валютой; `РазрешитьПродажу` — по `salesBan` позиции (или корня);
- при проведении цены попадают в `ЦеныПродажи` (измерения: номенклатура, вид цены, склад, валюта; ресурс `РазрешитьПродажу` — на той же связке).

**Пример:**

```http
POST /trade/hs/stock/prices
X-Api-Key: your-api-token-here
Content-Type: application/json
```

```json
{
  "priceType": "Крупный опт",
  "currency": "USD",
  "warehouseCode": "1",
  "items": [
    {
      "itemCode": "10001",
      "salesBan": false,
      "price": [
        { "qty": 0, "priceQty": 12.5 },
        { "qty": 10, "priceQty": 11.0 },
        { "qty": 50, "priceQty": 10.0 }
      ]
    },
    {
      "itemCode": "10002",
      "salesBan": true,
      "price": [
        { "qty": 0, "priceQty": 8.0 }
      ]
    }
  ]
}
```

**Успешный ответ (200):**

```json
{
  "success": true,
  "error": "",
  "documentNumber": "000000123",
  "items": 2,
  "priceType": "Крупный опт",
  "currency": "USD"
}
```

| поле | описание |
| --- | --- |
| `success` | `true` при успешном проведении |
| `documentNumber` | номер созданного `УстановкаЦен` |
| `items` | число строк товаров в документе |
| `priceType` | наименование вида цены |
| `currency` | код валюты (`Код` справочника) |

**Ошибки:**

| код | когда |
| --- | --- |
| `401` | неверный или отсутствующий API-ключ |
| `400` | ошибки разбора/валидации: нет `priceType`/`currency`/`items`, склад/номенклатура/валюта/вид цены не найдены, пустой список позиций, обязательный сотрудник не передан и т.п. (`success: false`, текст в `error`) |
| `500` | внутренняя ошибка (в т.ч. более трёх порогов цен в `price[]`) |
