# GET `/api/v1/balances`

**Описание:**  
    получение остатков товаров на доступных складах учётной записи вместе с ценами продажи из регистра `ЦеныПродажи`. В выборку попадают только товары (`ТипНоменклатуры = Товар`) с остатком **> 0** и без `ЗапретОтгрузки`.

**Запрос**  
    GET /trade/hs/stock/balances

**Авторизация:**  
    заголовок `X-Api-Key` (токен [[Справочники (НСИ)/Учетные записи интеграции\|учётной записи интеграции]]).

**Параметры:**

| параметр | описание | обязательный |
| --- | --- | --- |
| `page` | номер страницы, начиная с 1 (по умолчанию `1`) | нет |
| `pageSize` \| `limit` | размер страницы, 1–500 (по умолчанию `500`) | нет |
| `warehouseCode` \| `warehouseId` \| `code` | числовой код склада | нет |
| `warehouse` | наименование склада | нет |
| `priceType` | наименование [[Справочники (НСИ)/Виды цен\|вида цены]] | см. ниже |
| `currency` | [[API/Валюты\|валюта]]: код справочника (`Код`) или код ISO (`КодISO`, приоритет — `Код`) | см. ниже |
| `itemCode` \| `itemCodes` | код номенклатуры или несколько кодов через запятую | нет |
| `item` | точное наименование номенклатуры | нет |
| `brand` | бренд: код или наименование группы первого уровня | нет |

**Режимы работы**

Метод поддерживает **два режима** в зависимости от параметров `priceType` и `currency`:

| `priceType` | `currency` | Режим |
| --- | --- | --- |
| не передан | не передан | все зарегистрированные цены по паре номенклатура+склад |
| передан | передан | один вид цены и одна валюта |
| передан только один из двух | | ошибка `400`: параметры заполняются **вместе** |

**Поведение (общее для обоих режимов):**

- склад проверяется по списку, доступному учётной записи; без параметра склада — остатки по **всем** разрешённым складам;
- `reserve` — резерв заказов по складу и номенклатуре;
- сортировка — склад, номенклатура;
- `balance` и `reserve` в JSON — строки;
- `warehouse` — код склада (строка);
- `currency` в ответе — реквизит `Код` справочника `Валюты`;
- `priceType` в ответе — наименование элемента справочника `ВидыЦен`.

**Пороги цен (`prices` / элементы `price[]`):**

- первый элемент всегда с `qty = 0` — базовая цена (`Цена0`);
- далее до трёх порогов: элемент добавляется, если соответствующая `Цена1..3` > 0; в `qty` — количественный порог (`Порог1..3`).

---

## Режим 1: без `priceType` и `currency`

Все цены из регистра `ЦеныПродажи` для каждой пары номенклатура+склад текущей страницы.

**Примеры:**

    GET /trade/hs/stock/balances
    GET /trade/hs/stock/balances?warehouseCode=1&pageSize=100
    GET /trade/hs/stock/balances?itemCodes=7720,9277&brand=Samsung

**Ответ 200**

```json
{
    "page": 1,
    "pageSize": 500,
    "totalItems": 728,
    "totalPages": 2,
    "items": [
        {
            "warehouse": "8",
            "item": "S26 S942B 12/256Gb Black HN",
            "itemCode": "7720",
            "brand": "Samsung",
            "brandCode": "18",
            "itemSku": "",
            "itemUpc": "",
            "itemJan": "",
            "manufacturer": "",
            "balance": "94",
            "reserve": "0",
            "price": [
                {
                    "priceType": "Крупный опт",
                    "currency": "RUB",
                    "prices": [
                        {"priceQty": 80000, "qty": 0},
                        {"priceQty": 79500, "qty": 10},
                        {"priceQty": 79200, "qty": 20}
                    ]
                },
                {
                    "priceType": "Мелкий опт",
                    "currency": "USD",
                    "prices": [
                        {"priceQty": 1000, "qty": 0},
                        {"priceQty": 990, "qty": 50}
                    ]
                }
            ]
        }
    ]

```

**Элемент `items[]` (режим без `priceType`/`currency`):**

| поле | описание |
| --- | --- |
| `warehouse` | код склада |
| `item` | наименование номенклатуры |
| `itemCode` | код номенклатуры |
| `brand` | наименование бренда |
| `brandCode` | код бренда |
| `itemSku` | SKU |
| `itemUpc` | UPC |
| `itemJan` | JAN13 |
| `manufacturer` | производитель |
| `balance` | остаток на складе |
| `reserve` | резерв заказов |
| `price` | массив всех цен; каждый элемент — `priceType`, `currency`, `prices[]` |

Если для товара на складе нет записей в `ЦеныПродажи`, поле `price` — пустой массив `[]`.

## Режим 2: с `priceType` и `currency`

Один вид цены и одна валюта; поля `priceType`, `currency`, `salesBan` дублируются на уровне каждого элемента `items[]`; массив `price` — плоский список порогов.

**Примеры:**

    GET /trade/hs/stock/balances?priceType=Крупный опт&currency=RUB&warehouseCode=8
    GET /trade/hs/stock/balances?priceType=Крупный опт&currency=RUB&itemCodes=7720,9277,10461

**Дополнительные поля `items[]` (режим с `priceType`/`currency`):**

| поле | описание |
| --- | --- |

| `currency` | валюта из запроса (`Код`) |
| `salesBan` | запрет продажи (`true`, если в регистре `РазрешитьПродажу = Ложь`) |
| `price` | массив порогов `{priceQty, qty}` для указанной пары вид цены + валюта |

---

## Поля ответа (общие)

| поле | описание |
| --- | --- |
| `page` | текущая страница |
| `pageSize` | размер страницы |
| `totalItems` | всего позиций (до пагинации) |
| `totalPages` | всего страниц |
| `items` | массив строк остатков |

**Ошибки:**

| код | когда |
| --- | --- |
| `401` | неверный или отсутствующий API-ключ |
| `400` | ошибки параметров: пагинация, склад недоступен, не найдены `item` / `itemCode(s)` / `brand` / `priceType` / `currency`, передан только один из `priceType` и `currency` и т.п. (`error` в теле) |
| `500` | внутренняя ошибка |
