# GET `/api/v1/balances`

**Название:** 
    получение остатков и цен товаров
**Описание:** 
    получение остатков и цен (только товары, которые есть на остатках склада)
**Запрос**
    GET /trade/hs/stock/balances
**Параметры:** 

| параметр                             | описание                                  | обязательный |
| ------------------------------------ | ----------------------------------------- | :----------: |
| warehouseId \| warehouseCode \| code | код [[API/Склады\|склада]]                    |      +       |
| priceType                            | [[Справочники (НСИ)/Виды цен\|вид цены]]                    |      +       |
| currency                             | [[API/Валюты\|валюта]]                        |      +       |
| brand \| brandCode                   | наименование или код [[API/Бренды\|бренда]]   |      -       |
| itemCode \| itemCodes                | код товара, или коды, разделенные запятой |      -       |

**Примеры:** 
	/stock/balances?priceType=Крупный опт&warehouse=Склад наш&itemCodes=7720,9277,10461

# GET `/api/v1/leftover`

**Описание:**  
    получение остатков товаров на доступных складах учётной записи **без** видов цен, валют и цен. Облегчённый вариант **GET /balances**: те же фильтры по [[API/Склады\|складу]]/номенклатуре/[[API/Бренды\|бренду]] и та же пагинация, но без обращения к регистру `ЦеныПродажи`.

**Запрос**  
    GET /trade/hs/stock/leftover

**Авторизация:**  
    заголовок `X-Api-Key` (токен [[Справочники (НСИ)/Учетные записи интеграции\|учётной записи интеграции]]).

**Параметры:**

| параметр | описание | обязательный |
| --- | --- | --- |
| `page` | номер страницы, начиная с 1 (по умолчанию `1`) | нет |
| `pageSize` \| `limit` | размер страницы, 1–500 (по умолчанию `500`) | нет |
| `warehouseCode` \| `warehouseId` \| `code` | числовой код склада; без параметра — остатки по всем складам, доступным учётной записи | нет |
| `itemCode` \| `itemCodes` | код номенклатуры или несколько кодов через запятую | нет |
| `item` | точное наименование номенклатуры | нет |
| `brand` | бренд: код или наименование группы первого уровня | нет |

**Поведение:**

- авторизация — заголовок `X-Api-Key`, как у остальных методов Stock API;
- склад проверяется по списку, доступному учётной записи (для администратора API — по общим складам);
- в выборку попадают только товары (`ТипНоменклатуры = Товар`) с остатком > 0 и без `ЗапретОтгрузки`;
- `reserve` = резерв партий + резерв заказов по складу и номенклатуре;
- сортировка — склад, номенклатура;
- в ответе **нет** полей `priceType`, `currency`, `price`, `salesBan` (в отличие от **GET /balances**).

**Примеры:**  
    GET /trade/hs/stock/leftover  
    GET /trade/hs/stock/leftover?warehouseCode=1&pageSize=100  
    GET /trade/hs/stock/leftover?itemCodes=10001,10002  
    GET /trade/hs/stock/leftover?brand=Apple&page=2&pageSize=50

**Ответ**

| поле | описание |
| --- | --- |
| `page` | текущая страница |
| `pageSize` | размер страницы |
| `totalItems` | всего позиций (до пагинации) |
| `totalPages` | всего страниц |
| `items` | массив строк остатков |

**Элемент `items[]`:**

| поле | описание |
| --- | --- |
| `warehouse` | код склада |
| `item` | наименование номенклатуры |
| `itemCode` | код номенклатуры |
| `brand` | наименование бренда (группа в иерархии номенклатуры) |
| `brandCode` | код бренда |
| `itemSku` | SKU номенклатуры |
| `manufacturer` | наименование производителя |
| `balance` | остаток на складе |
| `reserve` | резерв (партии + заказы) |

**Ошибки:**

| код | когда |
| --- | --- |
| `401` | неверный или отсутствующий API-ключ |
| `400` | ошибки параметров: пагинация, склад недоступен, не найдены `item` / `itemCode(s)` / `brand` и т.п. (`error` в теле) |
| `500` | внутренняя ошибка |
