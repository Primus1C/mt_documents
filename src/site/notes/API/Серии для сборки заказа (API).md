# GET `/api/v1/series`

**Описание:** метод возвращает [[Справочники (НСИ)/Партии и серии\|серии]] товаров, допустимые для заполнения [[API/Документы отгрузки (API)\|Расходной накладной]] указанного заказа (из имеющихся на остатках [[API/Склады (API)\|склада]], указанного в [[API/Заказы (API)📌\|Заказе]]) 

**Запрос**

    GET /trade/hs/stock/series

| параметр                                 | описание                                                        | обязательный                                   |
| ---------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------- |
| incomingNo \| incomingNumber \| incoming | номер входящий (нумерация заказчика) [[API/Заказы (API)📌\|Заказа]] | + (необязателен, если указан *номер 1С*)       |
| orderNo \| orderNumber \| order          | номер 1С                                                        | + (необязателен, если указан *номер входящий*) |

**Ответ**

Элемент `items[]`: `itemCode` — код номенклатуры, `productRange` — наименование ассортимента (пустая строка, если не заполнен), `serials` — серии на складе заказа.

```json
	{
	"orderNumber": "00001234",
	"incomingNumber": "PO-12345",
	"items": [
		{
			"itemCode": "5678",
			"productRange": "",
			"serials": ["SN001", "SN002", "SN003"]
		},
		{
			"itemCode": "4570",
			"productRange": "",
			"serials": ["SN500", "SN501"]
		}
	]
}
```
