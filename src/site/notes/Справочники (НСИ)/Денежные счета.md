# Денежные счета
Кассы и банковские счета фирмы. По счёту считаются остатки денег, пишутся [[Документы/📄Движение денег (кассовый ордер)\|движения денег]], печатаются реквизиты в [[Документы/📄Инвойс продажи\|инвойсе продажи]].
Это не то же самое, что [[Справочники (НСИ)/Фирмы\|фирма]] (юрлицо) или [[Справочники (НСИ)/Офисы\|офис]] (площадка). Счёт **принадлежит фирме** и обычно привязан к офису.
Справочник **иерархический**: папки (группы) и элементы (сами кассы/счета). Папка нужна только для группировки в списке: код, наименование, родитель.
Счёт выбирают в движении денег (касса операции и касса «куда» при перемещении/обмене), в инвойсе продажи (поля **Счет** и **Счет дополнительный** — для печати) и в возврате от покупателя.
Текущая касса сеанса задаётся в списке движений денег. Без выбранной кассы новый документ не открыть: «Не задана текущая касса!».
## Реквизиты элемента
| Поле | Назначение |
|------|------------|
| **Фирма** | Владелец счёта. Заполняется сама, на форме только просмотр. В учёте фирма фактически одна — см. [[Справочники (НСИ)/Фирмы\|Фирмы]] |
| **Родитель** | Папка в дереве счетов |
| **Код** | Числовой код. Меняет только администратор |
| **Наименование** | Имя кассы/счёта в документах и списках. Меняет только администратор |
| **Префикс** | Два символа в номере [[Документы/📄Движение денег (кассовый ордер)\|движения денег]]: префикс фирмы + префикс счёта. Если пусто — подставляется `ДС`. Меняет только администратор |
| **Реквизиты для печати** | Банковские/кассовые реквизиты текстом. Попадают в печатную форму инвойса продажи (основной и дополнительный счёт) |
### Платёжный календарь
Группа на карточке. Меняет только администратор.

| Поле | Назначение |
|------|------------|
| **Включать в платежный календарь** | Остаток этого счёта попадает в отчёт платёжного календаря |
| **Транзитная касса/счет** | В календаре остаток идёт в колонку **Ожидается**, а не **В наличии**. Для денег «в пути» (инкассация, перевод между счетами) |
| **Офис** | Площадка счёта. Календарь отбирает счета по офису — см. [[Справочники (НСИ)/Офисы\|Офисы]] |
Счёт без флажка «включать в платёжный календарь» в календарь не попадает, даже если по нему есть остаток.
### Учёт (партии валюты)
| Поле | Назначение |
|------|------------|
| **Вести партионный учет** | На этой кассе валюта учитывается партиями (по курсам поступления). Сама валюта тоже должна быть с партионным учётом |
| **с даты** | С какой даты партии по этой кассе начинают действовать |
Если по счёту уже есть проведённые движения денег, флажок и дату обычный пользователь не меняет (подсказка на поле). Роль «Разработка» это ограничение обходит.
Зачем это нужно: расход и перемещение партионной валюты контролируют остаток партий; обмен и ввод остатков пишут регистр партий. Подробности — в [[Документы/📄Движение денег (кассовый ордер)\|движении денег]] (виды «Перемещение», «Обмен валюты», «Ввод остатков»).
Нельзя переносить партионную валюту с кассы **без** парт.учёта на кассу **с** парт.учётом.
## Кто видит счёт
Список счетов у пользователя задаётся в карточке [[Справочники (НСИ)/Пользователи\|пользователя]], табличная часть **Денежные счета**.
- табличная часть пустая — в справочнике видны все счета;
- заполнена, флажок «Доступны все денежные счета кроме указанных» выключен — видны только перечисленные счета;
- заполнена и флажок включён — перечисленные счета скрыты, остальные видны.
Тот же список ограничивает выбор кассы в движениях денег. Чтобы работать с кассой, её нужно указать пользователю (или выбрать текущую кассу в списке документов, если счетов несколько).
## Практика
1. Заведите папки по смыслу (Кассы, Банки, Транзит).
2. Создайте элементы: понятное **наименование**, при необходимости **префикс** для номеров ордеров.
3. Укажите **офис**. Для рабочих касс включите **включать в платёжный календарь**.
4. Деньги «ещё не на кассе» заведите отдельным счётом с пометкой **транзитная**.
5. Реквизиты для печати заполните на счетах, которые ставят в инвойс продажи.
6. Партионный учёт включайте согласованно с валютой и датой начала; после первых проведённых документов флажок уже не переключается.
7. В карточке пользователя перечислите кассы, с которыми он работает.
## Примеры
**Касса расчетов с клиентами.** Офис заполнен, «включать в платёжный календарь» включено, транзит выключен. Остаток виден в календаре как **в наличии**. Кассир выбирает её текущей кассой и оформляет оплату покупателя.
**Транзит банк.** Включены «включать в платёжный календарь» и **транзитная касса**. Перевод с кассы магазина на расчётный счёт сначала сажают сюда: в календаре сумма в **ожидается**, пока не дойдёт до обычного счёта.
**USD в кассе.** Включено **вести партионный учет** с конкретной даты, у валюты USD тоже включён партионный учёт. Расход долларов проверяет партии; ввод остатков в день начала может записать в партии текущий остаток кассы по указанному курсу.
