Классификатор **товарных групп для подбора и группировки** номенклатуры в документах и печати. Это не папки справочника «Номенклатура» и не «товарные группы перевозчиков» — отдельный список категорий «как удобно подбирать товар».

### Как связывается с номенклатурой
Реквизит **Группа подбора** задаётся на **группе (папке)** номенклатуры, не на отдельной позиции.

Товар «наследует» группу через цепочку родителей: система ищет ближайшую заполненную **Группа подбора** у папки выше по иерархии.

### Где используется
| Место | Роль |
|---|---|
| **Установка цен** | Меню «заполнить по товарной группе»: по группам подбора строится подменю, внутри — папки номенклатуры с этой группой |
| **Отправка / Отправка AWB** | Поле **Товарная группа** (тип — группа подбора) |
| **Отправка перемещений** | Печатная форма затрат **по группам**: товары сворачиваются по группе подбора, взятой из родителей номенклатуры |
| **Сведения товарных групп перевозчиков** | Измерение регистра (связь с тарификацией перевозчика) |

### Практика настройки
1. Создайте группы с понятными именами (например, «Шины», «Диски», «Аксессуары»).  
2. В карточках **папок** номенклатуры укажите **Группа подбора**.  
3. Достаточно заполнить на нужном уровне дерева — вложенные позиции подхватятся по родителям.  
4. В **Установке цен** появятся команды заполнения по этим группам.  
5. В отправках и печати затрат товары попадут в нужную товарную группу.

### Важно
- Не путать с **папками номенклатуры** (структура каталога) и с **товарными группами перевозчиков** (тарифы конкретного перевозчика).  
- Без заполнения на папках подменю в установке цен пустое, а в печати отправки будет «группа подбора не определена».
