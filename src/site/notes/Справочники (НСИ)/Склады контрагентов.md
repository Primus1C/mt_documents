Справочник точек отправки и получения у [[Справочники (НСИ)/Контрагенты\|контрагентов]] (склады поставщиков, логистов и т.п.). Это не собственные склады фирмы (`Склады`) — отдельные объекты для закупок и логистики.
### Карточка склада

| Поле         | Назначение                                              |
| ------------ | ------------------------------------------------------- |
| Наименование | Как склад отображается в документах                     |
| Офис         | Связанный [[Справочники (НСИ)/Офисы\|офис]]                               |
| Статья       | Статья движения денег; допустимы только доходные статьи |
| Отправитель  | Можно выбирать как склад-отправитель                    |
| Получатель   | Можно выбирать как склад-получатель                     |

Один склад может быть и отправителем, и получателем — или только одним из них.
### Где используется

- Инвойс закупки — склад отправителя / получателя (в списках выбора — по флагам)
- [[Документы/Отправка\|Отправка]], [[Документы/Отправка AWB\|Отправка AWB]], [[Документы/Отправка перемещений\|Отправка перемещений]] — склад отправителя / получателя
- Отчёты по закупкам и логистике (остатки в пути, реестр затрат, платёжный календарь и др.)

В настройках пользователя есть значение по умолчанию «Склад отправителя».

### Ограничение доступа

В карточке  [[Справочники (НСИ)/Пользователи\|пользователя]]  — табличная часть Склады контрагентов:

- пусто — видны все склады;
- заполнено — в списках и выборе доступны только указанные склады.

Список можно скопировать от другого пользователя командой на форме.

### Практика

1. Заведите склады с понятными именами.
2. Отметьте Отправитель / Получатель.
3. При необходимости укажите Офис и доходную Статью.
4. Для ограниченных ролей — заполните ТЧ в карточке [[Справочники (НСИ)/Пользователи\|пользователя]].
