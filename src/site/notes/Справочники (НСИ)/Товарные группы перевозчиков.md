Справочник задаёт товарные группы конкретного перевозчика: какие группы номенклатуры относятся к какой категории для расчёта затрат на перевозку.

### Назначение

У разных перевозчиков свои правила тарификации (по типу груза). В системе для каждого перевозчика заводятся свои группы; в них указывают группы [[MT/Справочники (НСИ)/Номенклатура\|номенклатуры]]. При распределении затрат в [[Отправка премещений\|Отправке перемещений]] сумма относится только к товарам нужной группы перевозчика (обычно пропорционально весу).

### Структура

| Поле               | Смысл                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------- |
| Владелец           | Перевозчик ([[Справочники (НСИ)/Контрагенты\|контрагент]])                                              |
| Код / наименование | Код с автонумерацией; имя группы (как у перевозчика)                                  |
| Товары             | Список групп [[MT/Справочники (НСИ)/Номенклатура\|номенклатуры]] (папки справочника, не отдельные позиции) |

В карточке доступен Подбор групп номенклатуры. Одна и та же группа в одной карточке повторно не добавляется.

Подчинение: группы ведутся в разрезе перевозчика. У каждого перевозчика — свой набор групп.

### Как используется

В документе Отправка перемещений:

1. По перевозчику и составу груза система определяет товарную группу перевозчика для каждой номенклатуры (по вхождению в иерархию указанных групп).
2. В таблицах Затраты и Распределение затрат указывается эта группа.
3. При распределении: если у затраты задана группа — сумма делится между строками этой группы (по весу); без группы — товар учитывается как «без тов. группы».

Товары вне настроенных групп получают пустую группу и в «групповое» распределение не попадают.

### Практика настройки

1. Выберите перевозчика-владельца.
2. Создайте группы с понятными именами (как в тарифах перевозчика).
3. В Товары подберите соответствующие папки номенклатуры.
4. Не пересекайте одни и те же папки между группами одного перевозчика без необходимости — иначе приоритет будет зависеть от порядка обхода.
5. Проверьте распределение затрат в отправке с этим перевозчиком.

### Важно

- Это не группы подбора номенклатуры и не общие товарные группы фирмы — только классификация для перевозчика.
- В ТЧ указываются группы номенклатуры; позиции внутри папки подхватываются автоматически по иерархии.
