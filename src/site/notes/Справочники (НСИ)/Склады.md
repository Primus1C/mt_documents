# Склады

Собственные места хранения фирмы: основной склад, склад комиссии, склад интернет-площадки. По складу считаются остатки, резерв и движения товарных документов.

Точки поставщиков и логистов — отдельный справочник [[Справочники (НСИ)/Склады контрагентов\|Склады контрагентов]].

Справочник **без папок**: каждый элемент — один склад.

Склад выбирают в [[Документы/📄Приходная накладная\|приходной накладной]], [[Документы/📄Расходная накладная\|расходной накладной]], [[Документы/📄Перемещение\|перемещении]], инвентаризации и [[Документы/📄Инвойс продажи\|инвойсе продажи]]. Через API площадка работает только со складами, указанными в её [[Справочники (НСИ)/Учетные записи интеграции\|учётной записи интеграции]].

## Реквизиты

| Поле                                        | Назначение                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Код**                                     | Числовой код склада                                                                                                                                                                                                                                                                                                                   |
| **Наименование**                            | Имя склада в документах и списках при русском языке интерфейса                                                                                                                                                                                                                                                                        |
| **Наименование англ**                       | Имя для английского языка интерфейса. Если поле пустое, при записи в него копируется наименование                                                                                                                                                                                                                                     |
| **Склад комиссии**                          | Этот склад хранит товар, переданный комиссионеру. В расходной накладной с признаком комиссии и в отчёте комиссионера можно указать только склад с этой пометкой                                                                                                                                                                       |
| **Ассортимент**                             | Канал продаж этого склада: Ozon, Wildberries и т.п. См. [[Справочники (НСИ)/Ассортимент\|Ассортимент]]. При создании товара через API ассортимент копируется со склада на новую карточку номенклатуры. Если поле пустое, API товар не создаст и вернёт «У склада ХХХ не установлен ассортимент в 1С». Поле видно пользователю с флажком «Дополнительный ассортимент» |
| **Резервировать товар даже при отсутствии** | При записи [[Документы/📄Инвойс продажи\|инвойса продажи]] по этому складу включается резерв товара. Заказ через API принимается и тогда, когда свободного остатка не хватает, и резерв в заказе включается                                                                                                                                     |
| **Размещать заказы на товары без остатков** | Заказ через API по этому складу тоже принимается без проверки «хватает ли остатка», и резерв в заказе включается. При ручной записи инвойса этот флажок сам резерв не включает — это делает предыдущий                                                                                                                                |

Оба флажка заказов стоят на карточке в группе **API**.

На обычном складе, где оба флажка выключены, API сверяет количество в заказе со свободным остатком (остаток минус уже зарезервированное). Если остаток есть, но его меньше, чем в заказе, заказ не принимается. Если свободного остатка нет совсем, такая сверка заказ не останавливает.

## Кто видит склад

Список складов у пользователя задаётся в карточке [[Справочники (НСИ)/Пользователи\|пользователя]], табличная часть **Склады**.

- табличная часть пустая — пользователю видны все склады;
- заполнена, флажок «Доступны все склады кроме указанных» выключен — видны только перечисленные склады;
- заполнена и флажок включён — перечисленные склады скрыты, остальные видны.

Тот же список ограничивает выбор склада в документах.

## Операторы

Внизу карточки уже записанного склада есть список **Операторы**: сотрудники, у которых этот склад указан в карточке [[Справочники (НСИ)/Сотрудники\|сотрудника]]. Список только для просмотра. Уволенные и помеченные на удаление сотрудники в него не попадают. Принадлежность меняется в карточке сотрудника, не в карточке склада.

## Примеры

**Основной.** Обычный склад магазина. Ассортимент пустой, флажки комиссии и API выключены. Менеджер видит его в накладных. Заказ через API на 10 штук при свободных 2 штуках не пройдёт.

**Комиссия Иванов.** Включено **Склад комиссии**. В расходной накладной с комиссией этот склад указывают как склад, на который уходит товар комиссионеру. Склад без этой пометки в такое поле не подойдёт: проведение сообщит, что у склада комиссии должен быть признак склада комиссии. У контрагента-комиссионера этот склад можно записать в поле «Склад комиссии», и накладная подставит его сама.

**Ozon.** В **Ассортимент** указан Ozon, включено **Размещать заказы на товары без остатков**. Площадка создаёт товар через API и указывает этот склад — у товара появляется ассортимент Ozon. Заказ на 10 чехлов при двух свободных принимается, в инвойсе включается резерв. Если ассортимент на складе очистить, создание нового товара через API остановится с текстом про неустановленный ассортимент.
