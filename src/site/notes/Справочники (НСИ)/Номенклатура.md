Основной каталог товаров и услуг. Используется во всех документах закупки, продажи, склада и в отчётах по остаткам.

---

### Иерархия и папки
Справочник **иерархический**: есть **папки** (группы) и **элементы** (товары/услуги).  
Папки всегда сверху. Уровней вложенности **не ограничено**.

| Что | Для чего |
|---|---|
| **Папка** | Группировка ассортимента (бренд, линейка, категория) |
| **Элемент** | Конкретный товар или услуга, который выбирают в документах |
| **Родитель** | В какой папке лежит элемент или подпапка |

В папке задаются свойства **группы**, у товара — свойства **позиции**. Часть полей есть и у папки, и у элемента.

---

### Реквизиты папки (группы)
| Поле                            | Назначение                                                                                                      |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Код, Наименование**           | Идентификация группы                                                                                            |
| **Вид номенклатуры**            | Шаблон свойств и конструктора наименования. При смене можно **проставить тот же вид всем подчинённым** позициям |
| **Тип номенклатуры**            | Товар / не товар (общий для ветки)                                                                              |
| **Имя группы для конструктора** | Как группа участвует в автосборке наименования товара                                                           |
| **Группа подбора**              | Связь со справочником [[Справочники (НСИ)/Группы подбора номенклатуры\|Группы подбора номенклатуры]]                                                           |
| **Выводить из ассортимента**    | Пометка группы как выводимой; в дереве списка такие папки **подсвечены**                                        |

---

### Реквизиты элемента (товара / услуги)
| Поле                                  | Назначение                                                                                            |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Код, SKU, Наименование**            | Код автонумеруется; наименование — основное представление                                             |
| **Вид номенклатуры**                  | Набор доп. свойств и правила имени                                                                    |
| **Тип номенклатуры**                  | По умолчанию **Товар**. Не товар — показывается **Статья** (для затрат/ДС), скрываются товарные флаги |
| **Производитель, Основной поставщик** | Справочная аналитика                                                                                  |
| **Учет по сериям**                    | Нужна серия/ШК в складских документах                                                                 |
| **Услуги (не проверять остатки)**     | Услуга: остатки не контролируются                                                                     |
| **Запрет отгрузки**                   | Блокировка отгрузки по позиции                                                                        |
| **Вес, г**                            | Вес единицы                                                                                           |
| **Блок**                              | Карточка проверена и **заблокирована** для правок                                                     |
| **Описание, Наименование телеграм**   | Доп. тексты                                                                                           |
| **Статья**                            | Для нетоварных позиций                                                                                |

При записи с **Блок** обычный пользователь **не может** поставить пометку удаления (нужны роли администратора или блока изменений).

### Форма списка
Двухпанельный вид:

1. **Слева — дерево папок**  
2. **Справа — список позиций** выбранной папки  

| Элемент формы | Зачем |
|---|---|
| **Фильтр склады** | Остаток и резерв считаются по выбранным складам |
| **Только остатки** | Показать позиции с остатком (услуги в этом отборе не «спасаются») |
| **Искать номенклатуру** | Быстрый поиск и переход к позиции |
| **% вес тары** | Колонка **Брутто** = вес + процент тары |

Колонки списка: наименование, спецификация (флаг страны), блок, **остаток**, описание, **резерв**, производитель, учёт по сериям, вес, брутто, услуга, запрет отгрузки, код.

Особенности отображения:
- услуги и помеченные на удаление **подкрашиваются**;
- папки с **«Выводить из ассортимента»** в дереве выделены цветом;
- колонка **Остаток** видна только при доступе к остаткам;
- вес можно **изменить кликом** по колонке (роли: администратор / изменение номенклатуры / изменение веса);
- при закрытии формы запоминается текущая строка.

~~Дополнительно: генератор штрихкодов, отчёт «Вес номенклатуры».~~

### Форма выбора (из документов)
Та же схема **дерево + список**, фильтр складов и «Только остатки».  
Если выбор вызван со склада — склад подставляется и **нельзя сменить**.  
Уже выбранные позиции могут **подсвечиваться**, чтобы не брать повторно.

Отдельно есть **форма выбора группы** — только папки (например, привязка группы подбора). Там тоже подсветка уже выбранных и неактуальных.

---

### Карточка товара
- Наименование можно собрать **конструктором** (путь по папкам + свойства вида номенклатуры; у папки учитывается **Имя группы для конструктора**).
- После записи заполняются **доп. свойства / спецификация** по правилам наименования.
- При **Блок** форма только для просмотра (кроме спец. ролей); наименование правят роли изменения номенклатуры / блок / Telegram / администратор.

---

### Предопределённое
Папка **Служебные**:
- **Затраты инвойсов**
- **Дополнительные затраты**

Их не удаляют — используются в служебных схемах учёта затрат.

---

### На что обратить внимание
1. В документах выбирают **элементы**, не папки.  
2. Структура папок влияет на поиск, подбор и конструктор имени.  
3. Смена **вида** у папки может массово обновить все подчинённые товары.  
4. Список и выбор показывают **остатки/резервы** по фирме и фильтру складов — это не отдельный складской документ, а удобный просмотр.
