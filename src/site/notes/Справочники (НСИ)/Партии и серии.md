### Идеология

- Партия подчинена номенклатуре (владелец — карточка товара).
- Создаётся при оприходовании (в первую очередь из Приходной накладной), а не заводится вручную «впрок».
- Дальше по этой же партии идут остатки, продажи, комиссия, затраты — чтобы видеть себестоимость и происхождение товара.
- Для серийной номенклатуры обычно 1 единица = 1 строка = 1 партия + 1 серия; без серий партия объединяет количество одной позиции прихода с одной ценой.

### Реквизиты карточки

| Поле                                                 | Смысл                                                             |
| ---------------------------------------------------- | ----------------------------------------------------------------- |
| Номенклатура (владелец)                              | Товар партии                                                      |
| Код / наименование                                   | Код автонумерацией; имя вида `ПН_…` по дате прихода               |
| Документ прихода                                     | Приходная накладная-источник                                      |
| Поставщик, фирма, валюта, дата партии                | Контекст закупки                                                  |
| Цена закупки, цена со скидкой, цена в базовой валюте | Себестоимость (базовая пересчитывается при записи)                |
| Серия                                                | Строковый идентификатор (до 30 символов), не отдельный справочник |
| Годен                                                | Срок годности (если используется фирмой)                          |

### Участие в аналитике

Измерение Партия в регистрах:

- Остатки товара
- Продажи
- Товары на комиссии

Через партию в отчётах доступны: серия, поставщик, дата/цена прихода, связь с инвойсом прихода и т.п. (обороты товара, затраты партии, обороты одной партии и др.).

### Автоматическое создание

Партия создаётся программой при работе с приходной:

- добавление строк / сканирование серии (F7);
- буфер сканирования и связанные обработки.

При создании заполняются: владелец, документ прихода, поставщик, цена, валюта, дата, фирма, серия (если есть), цена со скидкой.

Ручное создание из меню обычно не требуется. Список партий номенклатуры — команда Партии из карточки товара / приходной.
### Заполнение и обновление

При записи приходной накладной по строкам с заполненной партией система:

- снимает пометку удаления, если партия снова в документе;
- синхронизирует наименование, поставщика, документ, дату, валюту, фирму, консигнацию, цены;
- подтягивает в строку ТЧ серию и цену закупки из партии (с учётом затрат отправок).

Цены партии можно менять из приходной (если нет запрещающих движений). Смена валюты документа обновляет валюту связанных партий.

### Пометка на удаление

- Строка убрана из приходной → при записи партия, оставшаяся «висячей» у этого документа, помечается на удаление.
- Строка снова появилась / партия снова в ТЧ → пометка снимается.
- Удалить строку с партией, по которой уже есть движения, нельзя («есть движения партии»).

Помеченные партии в обычной работе не используют; поиск «найти или создать» может найти и помеченную (по номенклатуре + документ + серия + фирма).
### Взаимосвязь с сериями

|              | Серия                                        | Партия                                    |
| ------------ | -------------------------------------------- | ----------------------------------------- |
| Что это      | Идентификатор единицы/партии товара (строка) | Учётная аналитика прихода и себестоимости |
| Где хранится | Реквизит партии и строки документов          | Справочник, подчинённый номенклатуре      |
| Когда нужна  | Если у номенклатуры включён учёт по сериям   | Всегда при партионном учёте остатков      |

**Правила:**

- одна серия не должна дважды оприходоваться (проверка в документе и по остаткам);
- при сканировании серии создаётся/назначается партия с этой серией;
- документ Замена серий меняет серию в карточке партии (остатки продолжают идти по той же партии);
- замена номенклатуры в партии меняет владельца партии.

> [!tldr] 
> Cерия — «какой экземпляр/номер», партия — «какой приход и какая себестоимость»; 
> для серийного товара они связаны один к одному, для несерийного партия живёт без серии.
