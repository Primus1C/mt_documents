Справочник с предопределенными элементами:

| Наименование  | Валюта по умолчанию |
| ------------- | ------------------- |
| `Крупный опт` | Руб                 |
| `Мелкий опт`  | USD                 |
Вид цен задается в карточке контрагента 1С или устанавливается [[API/Клиенты\|методом API]] `POST /counterparties`

Прайс товара строится для произвольного сочетания **Склад + Вид цены + Валюта** (см. [[Документы/📄Установка цен (продажи)\|📄Установка цен (продажи)]])

> [!attention] 
> Использование в (параметрах запросов) API - только по наименованию
