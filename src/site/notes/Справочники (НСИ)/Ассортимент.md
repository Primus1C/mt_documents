Ассортимент — это не отдельный прайс и не группа [[Справочники (НСИ)/Номенклатура\|номенклатуры]]. Это метка канала продаж: свои продажи, Ozon, Wildberries и любая другая площадка.

Весь товар лежит в одном справочнике **Номенклатура**. Ассортимент отделяет товары площадок от обычного склада, чтобы менеджер не путал их с тем, чем торгует сам, а площадка через API видела и создавала только свои позиции.

# Зачем так сделано

Площадка заводит свои карточки: свой код, своё имя, свои SKU. Эти карточки нужны ей для заказов и остатков, но в ежедневной работе обычного слада фирмы они мешают: список номенклатуры раздувается, в подбор попадают чужие позиции.

Поэтому товар площадки помечается ассортиментом. Обычный товар (продаваемый менеджерами) ассортимент не имеет.

# Как это связано

Один ассортимент — одна площадка.

1. В справочнике **Ассортимент** заводят элемент, например «Ozon». У него есть цвет: им подсвечиваются строки в списке номенклатуры.
2. Этот ассортимент ставят на склад площадки, например склад «Ozon».
3. Учётной записи API площадки в табличной части **Склады** оставляют только её склады.
4. Когда площадка создаёт товар через API, ассортимент берётся со склада. Свой ассортимент площадка не передаёт: у склада «Ozon» он уже «Ozon», и новый товар получает ту же метку.

Площадка работает со своими складами. Чужой склад ей недоступен, поэтому чужой товар она не создаёт и в своих запросах не использует.

# Кто что видит

**Обычный пользователь** (менеджер склада) — в карточке пользователя не включён «Дополнительный ассортимент».

В списке номенклатуры и при выборе товара в документ он видит только позиции без ассортимента: свой магазин. Товары Ozon, Wildberries и других площадок в справочнике скрыты. Папки при этом остаются.

Поле «Ассортимент» у товара, склада и контрагента ему не показывается.

**Сотрудник площадок** — флаг «Дополнительный ассортимент» включён, а в табличной части пользователя перечислены нужные ассортименты.

![Pasted image 20261022173009.png](/img/user/Assets/Pasted%20image%2020261022173009.png)

В списке номенклатуры появляется поле отбора по ассортименту. Первая строка в поле отбора — «<все>»: полный список товаров как есть. Дальше только те площадки, которые указаны этому сотруднику. Выбрал «Ozon» — видны папки и товары Ozon, строки товаров подсвечены цветом этого ассортимента.

**Отчёты** отбор справочника не применяют. Они читают документы и остатки. Товар площадки, которого нет в списке номенклатуры у обычного пользователя, в отчёте виден: приход, расход, остаток, продажа.

## Примеры

### Три ассортимента в одном справочнике

| Товар | Ассортимент | Кто видит в справочнике |
| --- | --- | --- |
| iPhone 15 128 ГБ | не заполнен | все |
| Чехол силикон | не заполнен | все |
| Чехол Ozon, артикул OZ-15 | Ozon | только сотрудники с доступом к Ozon |
| Наушники WB, артикул WB-88 | Wildberries | только сотрудники с доступом к Wildberries |

Менеджер склада открывает номенклатуру и видит iPhone и чехол. Двух карточек площадок в списке нет, выбрать их в накладную он не может.

### Площадка заводит свой товар

Ozon через API создаёт «Чехол Ozon, артикул OZ-15» и указывает склад «Ozon». У склада ассортимент «Ozon», поэтому у нового товара он тоже «Ozon».

Тот же запрос на склад «Wildberries» не пройдёт: этого склада нет в учётной записи Ozon. Запрос на склад без ассортимента вернёт ошибку про неустановленный ассортимент.

Дальше Ozon читает остатки и передаёт заказы по своим складам. Карточки Wildberries в эту работу не попадают.

### В справочнике нет, в отчёте есть

На склад «Ozon» пришло 20 чехлов OZ-15, затем 8 продано. Менеджер магазина по-прежнему не видит OZ-15 в номенклатуре.

Отчёт по остаткам показывает склад «Ozon», товар OZ-15 и остаток 12. Отчёт по продажам показывает эти 8 штук. Учёт площадки не прячется, прячется только лишний товар в справочнике.

### Сотрудник, который ведёт площадки

У Иванова включён «Дополнительный ассортимент», в карточке указаны Ozon и Wildberries.

Он открывает номенклатуру, выбирает «Ozon» и работает только с озоновскими карточками: они подсвечены цветом Ozon. Переключает на «Wildberries» — список другой. «<все>» снова показывает общий список, в том числе обычные товары склада.
