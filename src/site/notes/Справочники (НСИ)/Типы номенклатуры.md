У каждой позиции справочника Номенклатура задаётся тип. Он определяет, как позиция участвует в учёте.

|Тип|Для чего|Что важно|
|---|---|---|
|Товар|Физический товар на складе|Учитывается по остаткам, партиям, сериям (если включено). Участвует в приходе, расходе, перемещении, комиссии, остатках.|
|Услуга|Работы и услуги (не складской товар)|Не ведётся складской остаток. В карточке указывается статья доходов/расходов. В заказах и документах может идти отдельной строкой без списания со склада.|
|Затрата|Служебные позиции для учёта затрат|Используются при распределении затрат (например, затраты по инвойсу). Обычно не выбираются как обычный товар для продажи.|

### Как выбрать тип

- Продаёте или храните на складе → Товар.
- Оказываете услугу / без остатка на складе → Услуга.
- Нужна позиция для затрат в учёте → Затрата (как правило, через группы/предопределённые элементы).

> [!attention] 
> - Тип задаётся в карточке номенклатуры (для элемента обычно доступны *Товар* и *Услуга*).
> - Тип нельзя менять, если по номенклатуре уже есть проведённые документы.
> - Для нового элемента по умолчанию ставится *Товар*
