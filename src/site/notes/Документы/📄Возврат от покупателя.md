Документ оформляет возврат ранее проданного товара покупателем на ваш склад.

### Для чего нужен

- вернуть товар на склад;
- сторнировать продажу по связанной расходной накладной;
- уменьшить долг покупателя или оформить возврат денег (если включён соответствующий режим).

### Что происходит при проведении

- товар приходуется на склад (по партиям/сериям);
- уменьшается отражение продажи;
- корректируются расчёты с покупателем (долг) или движение по кассе;
- если расходная была по заказу с резервом — резерв может быть восстановлен.

### Ограничения

- дата возврата не должна быть раньше даты партии;
- нельзя вернуть партию, которая уже есть на складе (повторный приход той же партии блокируется);
- расходная накладная для возврата через API должна быть проведена и закрыта флагом Окончательно.


> [!attention] 
> Возврат всегда опирается на ранее оформленную продажу (расходную накладную). Это не списание «с нуля» и не возврат поставщику — для возврата поставщику используется отдельный документ.
