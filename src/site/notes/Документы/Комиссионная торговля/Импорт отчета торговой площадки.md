# Импорт отчёта торговой площадки

Обработка **Импорт отчета торговой площадки** загружает данные из отчётов маркетплейса (ориентир — **Яндекс.Маркет**: листы «Серийные номера» и «Отчёт о платежном поручении») и создаёт в 1С пару документов на каждый заказ:

1. **Передача на комиссию** (`ПередачаНаКомиссию`) — передача серийных товаров комиссионеру.
2. **Отчёт комиссионера** (`ОтчетКомиссионера`) — продажи и суммы из отчёта площадки, основание — передача.

Данные вставляются из Excel **Ctrl+V** в табличные поля на форме обработки (не через файловый импорт).

---

## Когда использовать

- Нужно массово оформить комиссионные продажи по отчёту площадки.
- Серии (IMEI и т.п.) уже есть в справочнике **Партии**, товар идентифицируется по серии.
- Для заказа известны номер на площадке, дата, строки с сериями и строки платежей.

---

## Порядок работы

1. Откройте обработку **Импорт отчета торговой площадки**.
2. Заполните **настройки документов** (сохраняются между сеансами).
3. При необходимости уточните **номера колонок** под ваш шаблон Excel (по умолчанию — под отчёт Яндекс.Маркет).
4. Вставьте данные в таблицу **Серийные номера** (с колонки A, как в Excel).
5. Вставьте данные в таблицу **Платежи**.
6. Установите флаги **Перезаполнять существующие** и **Проводить**, если нужно.
7. Нажмите **Импорт**.
8. Проверьте таблицу **Результат** и сообщение с итогами; при ошибках — колонку **Ошибка** и текст предупреждения.

---

## Настройки документов

| Поле | Назначение |
|------|------------|
| **Дата** | Если заполнена — эта дата подставляется **во все строки** серийных номеров. Если пустая — дата берётся из колонки «Дата» в таблице серий |
| **Контрагент** | Комиссионер (маркетплейс); обязателен |
| **Валюта** | Валюта создаваемых документов; обязательна |
| **Склад** | Склад и склад комиссии в документах; обязателен |
| **Статья передачи** | Статья для **ПередачаНаКомиссию**; обязательна |
| **Статья отчета продажи** | Статья для **ОтчетКомиссионера** (и комиссии в шапке); обязательна |

Перед импортом проверяется заполненность контрагента, валюты, склада и обеих статей.

---

## Флаги импорта

| Флаг | Поведение |
|------|-----------|
| **Перезаполнять существующие** | Если для заказа уже есть **ПередачаНаКомиссию** (тот же **номер заказа**, **контрагент**, **дата**), документы **перезаполняются** (предварительно снимается проведение). Без флага — ошибка «Уже существует передача…» |
| **Проводить** | После записи документы **проводятся**; иначе только запись |

---

## Лист «Серийные номера»

Строки без значения в колонке **Серия** пропускаются (можно вставлять шапку Excel — она не мешает, если в колонке серии пусто).

### Колонки по умолчанию

| № колонки | Содержимое |
|-----------|------------|
| 1 | Номер входящий (номер заказа на площадке) |
| 4 | Товар (наименование; используется при связке с платежами) |
| 3 | Количество |
| 5 | Дата заказа (если в шапке обработки **Дата** не задана) |
| 6 | Серия (IMEI и т.д.) |
| 7 | Цена |

Номера колонок можно изменить в блоке «Серийные номера» на форме.

### Идентификация товара

По **серии** ищется элемент справочника **Партии**. Если партия не найдена, строка попадает в ошибки идентификации; документы по этому заказу **не создаются**, если в группе заказа есть хотя бы одна такая строка.

Группировка в заказы: **дата** + **номер входящий** + **контрагент** из настроек.

---

## Лист «Платежи»

Используется для табличной части **ОтчетКомиссионера** и суммы комиссии в шапке.

### Колонки по умолчанию

| № колонки | Содержимое |
|-----------|------------|
| 8 | Номер входящий (номер заказа) |
| 13 | Товар (наименование; должно позволить связать строку с серийными номерами заказа) |
| 15 | Количество |
| 16 | Сумма, USD |
| 17 | Сумма, RUB |

### Товарные строки (количество > 0)

- Ключ строки: **товар + номер входящий**.
- Дубликат ключа в платежах — ошибка; импорт по заказу блокируется, если затронутый ключ помечен как дубль.
- Строки отчёта комиссионера формируются **только из платежей** с количеством > 0 и совпадающим номером заказа.

### Строки комиссии (количество ≤ 0)

- Суммы из колонки **USD** (16) **накапливаются** по номеру заказа.
- В шапке **ОтчетКомиссионера** поле **Сумма комиссии** заполняется этой суммой (со знаком «минус» в документе), валюта комиссии — **базовая валюта** учёта.

---

## Какие документы создаются

На **один заказ** (группа строк серийных номеров):

| Документ | Источник данных |
|----------|-----------------|
| **ПередачаНаКомиссию** | Все строки серий заказа: номенклатура и партия по серии, количество и **цена комитента** из листа серийных номеров, **цена закупки** из партии |
| **ОтчетКомиссионера** | Товарные строки из **платежей**; основание — созданная передача |

Поиск существующей передачи: **НомерЗаказа**, **контрагент**, **дата** (день). Связанный отчёт комиссионера ищется по **документу-основанию**.

---

## Цены в отчёте комиссионера

| Поле в **ОтчетКомиссионера.Товары** | Откуда |
|-------------------------------------|--------|
| **Количество** | Лист **Платежи** |
| **Цена**, **Сумма** | Из строки **ПередачаНаКомиссию** (**Цена комитента** × количество). Цена комитента = колонка **Цена** листа серийных номеров |
| **Цена комиссионера** | Лист **Платежи**: если валюта документа — рубль, берётся сумма из колонки RUB, иначе USD; **делится на количество** строки платежа |

Связка строки платежа с передачей: по очереди серийных строк с тем же **наименованием товара** в заказе, затем по **партии** или **номенклатура + серия**.

### Контроль расхождений

В форме документа **ОтчетКомиссионера** поле **Цена комиссионера** подсвечивается **красным**, если оно **не равно** полю **Цена** — так видно расхождение между ценой передачи (Excel, серийные номера) и ценой из отчёта площадки (Excel, платежи).

---

## Таблица «Результат»

| Колонка | Описание |
|---------|----------|
| **Номер входящий** | Заказ площадки |
| **Дата** | Дата заказа |
| **Передача на комиссию** | Ссылка на созданный или найденный документ |
| **Отчет комиссионера** | Ссылка на отчёт |
| **Ошибка** | Текст ошибки по заказу (если документы не созданы или заполнены с предупреждениями) |

После импорта показывается сообщение: **сколько комплектов документов создано** и **сколько перезаполнено**, плюс общий список ошибок идентификации (серии, дубли платежей и т.д.).

---

## Типичные ошибки

| Сообщение / ситуация | Что проверить |
|----------------------|---------------|
| Не указан контрагент / валюта / склад / статья | Настройки документов |
| Нет строк для импорта | В таблице серийных номеров нет строк с заполненной **серией** |
| Не найдена партия по серии | Серия должна быть в **Партии** (не помечена на удаление) |
| Уже существует передача… | Включите **Перезаполнять существующие** или удалите/измените старые документы |
| Дубль ключа товар + номер входящий | В платежах две товарные строки с одной парой товар/заказ |
| Не найдена строка серийного номера в заказе | Наименование **Товар** в платежах должно совпадать с привязкой к сериям (порядок строк: каждая товарная строка платежа «съедает» следующую серийную строку с тем же товаром) |
| Не найдена строка в передаче на комиссию | Несовпадение серии/партии между платежом и передачей после заполнения |

---

## Рекомендации

- Перед первым импортом сверьте **номера колонок** на небольшом фрагменте отчёта.
- Убедитесь, что **наименования товаров** в листах серий и платежей согласованы (связь идёт по тексту поля **Товар**).
- Для повторной загрузки того же отчёта используйте **Перезаполнять существующие**; проведение снимается автоматически перед перезаполнением.
- После импорта откройте **ОтчетКомиссионера** и проверьте строки с **красной** ценой комиссионера.
