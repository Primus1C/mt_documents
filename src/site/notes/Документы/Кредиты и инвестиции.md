# Кредиты и инвестиции

Контур учёта денег инвесторов (займов): договор, движение по кассе, начисление процентов и отчёты. Все суммы расчётов хранятся в регистре **Расчеты по кредитам и займам** (контрагент, договор, валюта).

### Где открыть

| Что                    | Где (раздел → документ)                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------ |
| Выдача и возврат денег | **Деньги → Движения денег**, вид **Инвестиции**                                                              |
| Начисление процентов   | **Деньги → Начисление процентов по кредитам**                                                                |
| Отчёт по договорам     | **Деньги → Расчеты по займам**                                                                               |
| Обороты по инвестору   | **Деньги → Инвестиции**                                                                                      |
| Карточка договора      | справочник **Кредитные договоры** (подчинён контрагенту; открывается и при выборе договора в движении денег) |

---

### Как это работает

```text
1. Завести кредитный договор (контрагент, сумма, валюта, ставка, срок)
2. Движение денег / Инвестиции — принять деньги (+) или вернуть (−)
3. Раз в период — Начисление процентов по кредитам (Заполнить → Рассчитать → провести)
4. Смотреть обороты в отчётах
```

| Операция | Что происходит |
|---|---|
| Выдача (сумма > 0) | Деньги на кассу **и** приход в расчёты по договору |
| Возврат (сумма < 0) | Деньги с кассы **и** расход в расчётах по договору |
| Начисление процентов | Приход в расчёты по договору (касса не меняется) |

Пока движение денег по инвестициям не **окончательное**, в кассу и расчёты оно не попадает (как и прочие виды — сначала **Установить**). Для инвестиций «незакрытый документ» не ведётся.

---

## 1. Кредитный договор

Карточка договора принадлежит **контрагенту** (владельцу). Один контрагент может иметь несколько договоров.

| Поле | Назначение |
|---|---|
| **Наименование, код** | Как видите договор в списках |
| **Контрагент** | Инвестор / заёмщик — владелец договора |
| **Процентная ставка** | **Месячная** ставка, % |
| **Дата начала / дата окончания** | Срок действия. Пустая дата = срок не ограничен |
| **Сумма** | Сумма договора — база для процентов |
| **Валюта** | Валюта договора и расчётов |
| **Примечание** | Свободный текст |

Ставка и валюта подставляются в **Движение денег**, когда выбираете договор. Сумма договора сама по себе кассу не двигает — только выдача через кассовый документ.

---

## 2. Выдача и возврат (Движение денег)

Подробно про кассовый документ — в [[📄Движение денег (кассовый ордер)_\|Движение денег]]. Здесь — только вид **Инвестиции**.

1. Создайте **Движение денег**, вид **Инвестиции**.
2. Укажите **контрагента**, **денежный счёт**, **сумму**.
3. Выберите **договор** этого контрагента. Подставятся **процент инвестиций** (только просмотр) и **валюта** договора.
4. Знак суммы:
   - **плюс** — получили деньги инвестора;
   - **минус** — вернули деньги инвестору.
5. **Установить** (окончательно) — чтобы операция попала в кассу и в расчёты.

Договор в выборе ограничен выбранным контрагентом. Если контрагента сменить, договор очищается.

Процент в проведении кассового документа не участвует: он нужен для карточки договора и для начисления процентов.

---

## 3. Начисление процентов

Документ **Начисление процентов по кредитам** считает проценты за период по действующим договорам и записывает их в расчёты (без движения по кассе).

### Шапка

| Поле | Назначение |
|---|---|
| **Дата, номер** | Дата документа (она же дата движений при проведении) |
| **Дата начала / дата окончания** | Период, за который начисляете проценты |
| **Примечание** | Свободный текст |

Обе даты периода обязательны, начало не позже окончания. Иначе **Заполнить** и **Рассчитать** не выполнятся — будет сообщение.

### Таблица «Начисления»

| Колонка | Назначение |
|---|---|
| **Контрагент** | Владелец договора |
| **Договор** | Кредитный договор |
| **Ставка** | Месячная ставка на момент заполнения |
| **Сумма** | Сумма процентов за период |

### Заполнить

Команда на панели табличной части. Подбирает договоры, которые **действуют в периоде документа**:

- не помечены на удаление;
- дата начала договора пустая **или** не позже даты окончания периода;
- дата окончания договора пустая **или** не раньше даты начала периода.

В строки попадают контрагент, договор, ставка; сумма сначала 0. Если таблица уже заполнена — программа спросит подтверждение очистки.

### Рассчитать

Считает **сумму** по каждой строке.

**База** — сумма из карточки договора (не остаток регистра).  
**Ставка** — месячная, из строки.  
**Доля** — календарные дни периода (включая обе границы) к числу дней месяца **даты начала** периода:

`Сумма = Сумма договора × Ставка / 100 × Количество дней периода / Дней в месяце даты начала`

Примеры:

- период — весь январь → полная месячная сумма (`31/31`);
- период — 10 дней января → `10/31` месячной суммы;
- пустая таблица — сначала **Заполнить**.

После расчёта проверьте строки и **проведите** документ. В регистр расчётов уйдёт **приход** на сумму каждой ненулевой строки.

## 4. Отчёты

### Расчеты по займам

Параметр: **период**.

Строки: **контрагент → договор** (рядом **процентная ставка**).  
Колонки сумм — **по валютам**, которые были в движениях за период:

| Колонка | Что показывает |
|---|---|
| **Начислено** | Приход по документам **Начисление процентов по кредитам** |
| **Выдано** | Приход по **Движению денег** (получение денег инвестора) |

Возврат инвестору (расход по кассовому документу) в эти колонки не входит.

### Инвестиции

Параметр: **период** (можно отобрать контрагента).

Обороты регистра за период: контрагент, валюта, сумма. В колонках — валюты. Удобно смотреть общий оборот по инвестору без разбивки на договоры.

---

## На что обратить внимание

- Без **договора** выдача в движении денег не попадёт в разрез договора в расчётах и отчёте по займам.
- Менять **сумму договора** после выдачи можно, но проценты считаются от суммы в карточке на момент **Рассчитать**, а не от остатка долга.
- Ставка **месячная**. Неполный месяц режется по дням относительно месяца даты начала периода документа.
- Начисление не списывает кассу: выплата процентов инвестору — отдельное **Движение денег** (обычно возврат с минусом или другой вид, если так принято у вас).
- Чтобы отчёты совпали с кассой, движения по инвестициям должны быть **окончательными** и проведёнными.
