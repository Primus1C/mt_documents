# Цены закупки 

При записи приходной накладной, связанной с [[Документы/📄Инвойс\|инвойсом]], цены закупки в таблице товаров **подставляются автоматически** по данным оприходования инвойса (с учётом номера поставки, если инвойс разделён на поставки).

**Как выбирается цена**

- Одна и та же номенклатура с разными ценами в инвойсе учитывается **отдельно по каждой цене**, без усреднения.
- Для серийной номенклатуры:
	- Цены (одного товара) переносятся в накладную по порядку: начала более низкая цена, затем следующая.
- Для номенклатуры без серий:
	- Количество из накладной закрывается по порядку: сначала более низкая цена, затем следующая.
	- Если одна строка затрагивает несколько цен, она **разбивается** на несколько строк с разными ценами.

**Частичное оприходование**

Можно оприходовать не весь товар инвойса. Уже оприходованное другими накладными количество в расчёт не берётся: следующая накладная получает цены только по **ещё не закрытому** остатку.

**Если в накладной товара больше, чем по инвойсу**

Лишнее количество остаётся в таблице с **нулевой ценой закупки** — его нужно проверить вручную.

> [!attention] 
> Цены пересчитываются при каждой записи документа по этому правилу. Имеет смысл сначала указать нужные количества по номенклатуре, затем записать накладную и проверить получившиеся строки и цены.

# Расчет затрат

Расчет затрат происходит при заполнении документа в форме (для удобного интерактива) и перед записью документа (на случай перепроведения). 
### Закладка "Затраты"
На закладке Затраты — только привязка документов «Дополнительные затраты» (`ВКД_ДополнительныеЗатраты`) к этой ПН.

В таблице: документ затрат, его сумма/валюта, сумма наценки по строке. Сверху — итог `ВКД_СуммаЗатрат` и вариант распределения (не распределять / по сумме / по количеству); кнопка Рассчитать затраты раскидывает эти суммы в цену с затратами по товарам.

Сюда не попадают затраты Отправки, ОтправкаAWB, логистики инвойса / ДД — они учитываются отдельно при расчёте строк товаров (через `ЗатратыОтправки` и `ЗатратыЛогистикиИнвойса`), не через эту ТЧ.

---

> [!summary] 
> **Перед записью**
> - Для накладных, созданных на основании [[Инвойса\|Инвойса]], перезаполняются цены из Инвойса (без изменений и перерасчета)
> - Создаются/обновляются партии по реквизитам строки таб.части. Партии, ставшие неактуальными, помечаются на удаление. 
> - Рассчитываются затраты
