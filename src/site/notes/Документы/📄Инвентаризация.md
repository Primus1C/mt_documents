Документ для **фиксации фактического наличия** товара на складе (складах) путём сканирования серий / штрихкодов. Это **ведомость пересчёта**, а не документ списания или оприходования: движений по остаткам склада он **не формирует**.

### Где открыть
**Закупки → Инвентаризация**  
(нужна роль доступа к инвентаризации; список отбирается по складам пользователя)

---

### Шапка
| Поле | Назначение |
|---|---|
| **Дата, номер** | Когда проводился пересчёт |
| **Один склад / Склад** | Пересчёт на одном складе |
| **Список складов** | Несколько складов в одном документе (если снят режим «один склад») |
| **Окончательно** | Документ закрыт, строки недоступны для правки |
| **Режим предупреждения** | Как сообщать об ошибках: текст / голос |

---

### Табличная часть «Товары»
| Колонка          | Смысл                                              |
| ---------------- | -------------------------------------------------- |
| **Номенклатура** | Товар (подбирается по серии из справочника партий) |
| **Серия**        | Отсканированный ШК / серия                         |
| **Партия**       | [[Справочники (НСИ)/Партии и серии\|Партия]] с этой серией           |
| **Количество**   | Обычно 1 на каждое сканирование                    |

---

### Как работать
1. Укажите склад (или несколько).  
2. Сканируйте серии сканером или вводите в поле ручного ШК.  
3. Каждое сканирование добавляет строку и **сразу записывает** документ.  
4. По окончании пересчёта — **Установить «Окончательно»** (документ проводится и блокируется).  
5. При необходимости снимите «Окончательно» командой **Снять** и продолжите.

---

### Контроль при сканировании
| Ситуация | Поведение |
|---|---|
| Серия уже есть в **этом** документе | Строка не добавляется (если включено предупреждение о дублях) |
| Серия уже есть в **другой** инвентаризации **за тот же день** | Строка не добавляется |
| Товар по ШК не найден | Предупреждение; строка с пустой номенклатурой всё равно может добавиться |
| Серия на другом складе | Проверка **отключена** (в коде закомментирована) |

---

### Печать
- **Инвентаризация** — итоги по номенклатуре (без детализации серий) и склады документа.  
- **Инвентаризации за день** — все **проведённые** инвентаризации за дату документа: номенклатура + серия + количество.

Из строк доступны отчёты по оборотам номенклатуры / партии / серии.

---

### Важно
- Документ **не меняет остатки** склада — только фиксирует, что насчитали.  
- После **«Окончательно»** правка строк закрыта; снять флаг можно командой **Снять**.  
- Удобен для серийного товара: один скан = одна единица.
