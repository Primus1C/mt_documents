**Запрет** = операция блокируется (`Отказ`, строка не принимается). **Предупреждение** = сообщение, документ/строка могут продолжить.

---

### Приходная накладная

| Когда | Тип | Проверка |
|---|---|---|
| Ввод/скан серии (форма) | **Запрет строки** | Серия уже в этом документе |
| Ввод/скан серии (форма) | **Запрет строки** | Серия на остатках/в резерве (любые склады) — «уже было оприходовано» |
| `ВводСтрокиПН` | **Предупреждение** | По серии был расход (ранее продана) — только инфо |
| Изменение количества (форма) | **Запрет** | У серийной номенклатуры нельзя менять кол-во («удалите строку») |
| `ОбработкаПроверкиЗаполнения` (запись/проведение) | **Запрет** | По серии уже есть остаток на фирме+складе документа (кроме безусловного проведения) |
| `ПередЗаписью` / проведение / отмена | — | Отдельных проверок серий нет; отмена — по «Окончательно» / непустоте |

---

### Расходная накладная

| Когда | Тип | Проверка |
|---|---|---|
| Скан/подбор (форма) | **Запрет строки** | Нет остатка по серии / партия уже в документе |
| `ОбработкаПроведения` | **Запрет** | У `УчетПоСериям` пустая серия |
| `ОбработкаПроведения` | **Запрет** | Нехватка остатка по партии (не по строке серии как таковой) |
| Проведение | ~~Запрет~~ | **Отключено:** дубли серий + `РазрешитьДублиСерий` |
| Отмена проведения | — | Не по сериям («Окончательно» / непустой) |

---

### Перемещение / Возврат поставщику

| Когда | Тип | Проверка |
|---|---|---|
| Скан/вставка (форма) | **Запрет строки** | Нет остатка по серии (у возврата — ещё поставщик/валюта) |
| Проведение | — | Контроль остатков по **партии**; пустую/дубль серии объект **не** проверяет |
| Отмена | — | Не по сериям |

---

### Возврат от покупателя

| Когда | Тип | Проверка |
|---|---|---|
| Скан/вставка (форма) | **Запрет строки** | Нет продажи по серии; серия уже в документе |
| Проведение / запись | — | Проверок серий в объектном модуле нет |

---

### Замена серий

| Когда | Тип | Проверка |
|---|---|---|
| Форма / проведение | **Запрет** | Не заполнены номенклатура / партия / серия; для замены серий — пустая «серия новая» |
| Форма | **Запрет строки** | Дубль старой/новой серии в ТЧ; нет остатка старой серии |
| Проведение | **Запрет** | Нет остатка по старой серии |
| `ПередЗаписью` | **Запрет** | Если замена уже проведена — нельзя менять |
| **Отмена проведения** | **Запрет** | Всегда запрещена (`Отказ = Истина`) |

---

### Инвентаризация

| Когда | Тип | Проверка |
|---|---|---|
| Скан (форма) | **Запрет строки** | Дубль ШК в документе (если включено предупреждение о дублях); серия уже в другой инвентаризации |
| Скан | **Предупреждение** | Неизвестный ШК — строка всё равно может добавиться |
| Запись / проведение | — | Проверок серий в объекте нет |

---

### Комиссия

| Документ | Проведение | Форма (скан) |
|---|---|---|
| **Передача на комиссию** | **Запрет:** дубли серий (`ПроверитьДубли`) + остатки | **Запрет:** нет остатка по серии |
| **Отчёт комиссионера** | **Запрет:** дубли серий + остатки | **Предупреждение:** нет остатка (серия может остаться) |
| **Переоценка на комиссии** | **Запрет:** дубли серий + остатки | **Запрет:** нет остатка по серии |
| **Возврат с комиссии** | Остатки/товары; **дубли серий не проверяются** | **Запрет:** нет остатка по серии |

---

### Отправка / Отправка AWB / Отправка перемещений

Проверок и запретов по **сериям** при записи/проведении **нет** (серийный учёт в ТЧ этих документов не валидируется).

---

### Сводка коллизий по типам

| Коллизия | Где реально запрещается |
|---|---|
| Пустая серия при `УчетПоСериям` | Расходная (проведение); Замена серий |
| Дубль серии в одном документе | Комиссия: передача / отчёт / переоценка (проведение); формы прихода/замены/инвентаризации/возврата |
| Серия уже на складе (повторный приход) | Приходная: форма + `ОбработкаПроверкиЗаполнения` |
| Серия ранее продана (повторная закупка) | Только **предупреждение** (`ВводСтрокиПН`) |
| Нет остатка серии при списании/перемещении | Формы расходной/перемещения/возвратов/комиссии; проведение — через партию/остатки |
| Отмена проведения из‑за серий | Только **Замена серий** (отмена запрещена целиком) |

Общий помощник дублей: `ПроведениеДокументов.ПроверитьДубли` (поле по умолчанию — `Серия`).
