## Автоматическое перепроведение после затрат и логистики

После проведения **Движения денег** с заполненной табличной частью **Инвойсы** (вид **Логистика** или **Оплата поставщику**) система сама обновляет связанные документы, чтобы в приходных и расходных накладных пересчитались **цены с затратами**.

Вручную перепроводить [[Документы/📄Инвойс\|инвойсы]], [[Документы/📄Приходная накладная\|приходные]] и [[Документы/📄Расходная накладная\|расходные]] накладные для этого **не нужно** — достаточно дождаться регламентного задания (или оно уже отработает в фоне).

---

### Зачем это нужно

Затраты и Логистика списывают деньги с кассы и раскладывает сумму на товары закупочного [[Документы/📄Инвойс\|инвойса]]. Без перепроведения зависимых документов:
- в инвойсе затраты уже есть;
- в **приходной** цена с затратами остаётся старой;
- в **расходной** закупочная / цена с затратами и наценка тоже старые.

Цепочка как раз «дотягивает» цены до актуальных затрат.

---

### Цепочка проведения

```text
┌─────────────────────────────────────┐
│  Движение денег                     │
│  (Логистика / ТЧ «Инвойсы»)         │
│  • расход с кассы                   │
│  • доли сумм по инвойсам            │
└─────────────────┬───────────────────┘
                  │ ставит в очередь
                  ▼
┌─────────────────────────────────────┐
│  Инвойс закупки (_Инвойс)           │
│  • перепроводится                   │
│  • пишет/обновляет регистр Затраты  │
│    (логистика по весу на товары)    │
└─────────────────┬───────────────────┘
                  │ ставит в очередь
                  ▼
┌─────────────────────────────────────┐
│  Приходная накладная                │
│  • перепроводится                   │
│  • обновляет цену с затратами       │
│    (в т.ч. логистика инвойса)       │
└─────────────────┬───────────────────┘
                  │ ставит в очередь
                  ▼
┌─────────────────────────────────────┐
│  Расходная накладная                │
│  • перепроводится                   │
│  • обновляет закупочную /           │
│    цену с затратами и наценку       │
└─────────────────────────────────────┘
```

Порядок жёсткий: **сначала инвойс → потом приходная → потом расходная**. Так расходная всегда видит уже обновлённые затраты.

---

### Что происходит по шагам

| Шаг | Документ                | Результат для пользователя                                          |
| --- | ----------------------- | ------------------------------------------------------------------- |
| 1   | **Движение денег**      | Деньги списаны; инвойсы из ТЧ поставлены «к перепроведению»         |
| 2   | **Инвойс**              | На товары записаны затраты и логистика                              |
| 3   | **Приходная накладная** | В строках выросла / изменилась **цена с затратами**                 |
| 4   | **Расходная накладная** | Обновились закупочные показатели и наценка по партиям этой поставки |

Очередь документов: регистр **«Документы к проведению»**. Обработка — регламентное задание перепроведения.

---

### Важно: удаление инвойса из движения денег

Если в уже проведённом **Движении денег** убрать инвойс из табличной части и записать документ снова:

1. удалённый инвойс **тоже** попадает в очередь;
2. он перепроводится **без** этой логистики (затраты пересчитаются);
3. затем снова обновятся связанные приходные и расходные.

То есть и **добавление**, и **удаление** логистики по инвойсу проходят по одной и той же цепочке.

---

### Когда цепочка не трогает инвойс

В строке ТЧ **Инвойсы** стоит флаг **«Не пересчитывать приход товара»** — этот инвойс (пока он в документе) в очередь **не** ставится.  
Удалённые из ТЧ строки этот флаг уже не защищает: они перепроводятся всегда.

---

### Как проверить, что всё прошло

1. Провести / поставить **Окончательно** на движение денег с логистикой и инвойсами.  
2. Подождать фоновое перепроведение (или открыть **Документы к проведению** — очередь должна опустеть).  
3. Открыть инвойс — в затратах видна логистика.  
4. Открыть приходную по этому инвойсу — **цена с затратами** обновилась.  
5. Открыть расходную по партиям этой поставки — закупочные / с затратами обновились.

Если документ «завис» в очереди дольше суток — смотрите отчёт контроля ввода данных / журнал регистрации (ошибка перепроведения).

---

### Краткая шпаргалка

| Действие | Что обновится автоматически |
|---|---|
| Добавили логистику на инвойс | Инвойс → ПН → РН (цены ↑) |
| Убрали инвойс из ДД | Тот же инвойс → ПН → РН (логистика снята / пересчитана) |
| Поставили «Не пересчитывать…» | Этот инвойс из цепочки исключён |
