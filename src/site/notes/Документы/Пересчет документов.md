# Общее описание

Механизм предназначен для автоматического перезаполнения/перерасчета связанных документов при изменении пользователем данных в начальном документе цепочки.

Перерасчет происходит при записи каждого связанного документа, т.е. для актуализации данных достаточно записать/провести документ, входящий в цепочку. В момент записи/проведения документ анализирует исходные данные из уже существующих документов цепочки, обновляя (если это нужно) данные в себе самом.

При изменении значимых данных в начальном документе, все зависимые документы фиксируются в регистре сведений  Документы к проведению. Регламентное задание каждые 2 минуты просматривает содержимое этого регистра и проводит найденные документы (проведение каждого принудительно вызывает перерасчет).

| Документ в регистре                                     | Кто регистрирует    | Условие                                                           |
| ------------------------------------------------------- | ------------------- | ----------------------------------------------------------------- |
| Приходная накладная                                     | `Инвойс`            | Интерактивно (!) изменились цены закупки,  состав товаров инвойса |
| Расходная / возврат / комиссия (регистраторы `Продажи`) | Приходная накладная | Изменились партии (цена закупки)                                  |
| `Инвойс`                                                | Движение денег      | Оплата инвойса без ручного курса и с пересчётом прихода           |

# Разработчику

Регистр сведений `ДокументыКПроведению` — очередь на отложенное перепроведение. Запись ставит `ОбработкаДокументов.ЗарегистрироватьДокументКПроведению(Документ, Инициатор)`. Фактически добавляют документы три цепочки.

## 1. `Инвойс` (закупка) → Приходная накладная

Когда: 
- в `ПередЗаписью` (формы) инвойса, если `ЦеныБылиИзменены()` = Истина:
- новый инвойс с непустой ТЧ товаров;
- или изменилось число строк / номенклатура / `ЦенаЗакупки`.

Что попадает в регистр: проведённые приходные накладные, у которых в `ВКД_ОприходованиеНоменклатуры` есть расход по этому инвойсу.

Инициатор: ссылка инвойса.


## 2. Приходная накладная → документы продаж по изменённым партиям

Когда: при проведении ПН, если в `ПередЗаписью` были изменены реквизиты партий (`ДополнительныеСвойства.ИзмененныеПартии` не пуст) — в т.ч. `ЦенаЗакупки`, `ВКД_ЦенаСоСкидкой`, контрагент, дата партии и т.п.

Что попадает: регистраторы из `Продажи` по этим партиям — обычно:

- `РасходнаяНакладная`
- `ВозвратОтПокупателя`
- документы комиссии (`ПередачаНаКомиссию`, `ВозвратСКомиссии`, `ОтчетКомиссионера`), если они писали в `Продажи` с этой партией

Инициатор: ссылка приходной накладной.

Цепочка: смена цен в инвойсе → перепроведение ПН → перепроведение расходных/возвратов.

## 3. Движение денег → `_Инвойс`

Когда: подписка `ПроведениеДокументов` на `ПриЗаписи` любого документа → в обработчике обрабатывается только `ДвижениеДенег`, и только если не `ГрупповоеПерепроведениеДокументов`.

Что попадает: инвойсы из ТЧ `Инвойсы` этого ДД, если одновременно:
- инвойс проведён;
- `НеПересчитыватьПриходТовара` = Ложь;
- `КурсУстановленВручную` = Ложь.

Инициатор: ссылка движения денег.

При последующем проведении инвойса запись по нему из регистра очищается (пустой набор по измерению `Документ`).

Подписка на событие *ПроведениеДокументов* срабатывает на событие *ПриЗаписи(ДокументОбъект)* 
> [!Attention] 
> исключение - если она вызывается с параметром сеанса *ГрупповоеПерепроведениеДокументов = Истина*

В процедуре подписки:
- для **проведенных** документов [[Документы/📄Движение денег (кассовый ордер)\|📄Движение денег (кассовый ордер)]] выбираются **проведенные** док-ты [[Документы/📄Инвойс\|📄Инвойс]] из таб.части и [[Пересчет цен закупки в документах\|регистрируются к проведению]] (цель перепроведения инвойсов: рассчитать в них цены и суммы закупки по актуальным значениям курсов валют):
	- без пометки **Не пересчитывать приход товара** 
	- со значением вида курса  "ручн.-ср.взвеш" = **ср.взвеш** (т.е. курс не зафиксирован)
- другие документы - ничего не выполняется

Пометка *"Не пересчитывать приход товара"* в таб.части *"Привязки инвойсов"* док-та ДвижениеДенег предназначена для блокирования изменений в ПриходныхНакладных закрытых периодов.
