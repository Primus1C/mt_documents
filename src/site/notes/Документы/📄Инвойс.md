> В конфигурации это **инвойс закупки** (учёт счёта поставщика). Не путать с **`ИнвойсПродажи`** — проформой/заказом покупателя для продаж и StockAPI.

# Часть 1. Для пользователя

### Назначение

Документ **«Инвойс»** фиксирует в системе **счёт поставщика** по закупке: состав товаров, суммы в валюте поставщика и в **USD** (валюта учёта закупки), курс пересчёта, скидки, наценку, распределение по **поставкам** и связь с логистикой.

Создаётся **на основании** документа **`Инвойс закупки`**. На один инвойс закупки может быть несколько документов «Инвойс» с разным **видом операции** (см. ниже).

### Место в цепочке закупки

```
Инвойс закупки  →  Инвойс (_Инвойс)  →  Корректировка инвойса (при расхождениях)
                         ↓
                   Отправка / AWB / Перемещения
                         ↓
                   Приходная накладная (оприходование на склад)
```

### Виды операции

На один **Инвойс закупки** допускается **не более одного проведённого** документа «Инвойс» **каждого вида**:

| Вид операции | Назначение |
|--------------|------------|
| **Товар** | Основной инвойс по товарным позициям |
| **Доставка** | Инвойс на стоимость доставки |
| **Скидка** | Инвойс на скидку поставщика |

### Шапка документа — основные поля

| Поле                              | Смысл                                                                                                                                                                                                                                   |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Контрагент**                    | Поставщик                                                                                                                                                                                                                               |
| **Документ-основание**            | Инвойс закупки                                                                                                                                                                                                                          |
| **Вид операции**                  | Товар / Доставка / Скидка                                                                                                                                                                                                               |
| **Валюта**                        | Валюта **закупочных** сумм (обычно **USD**)                                                                                                                                                                                             |
| **Курс**                          | Курс пересчёта из валюты инвойса поставщика в USD: «1 [валюта инвойса] = X USD»                                                                                                                                                         |
| **Курс установлен вручную**       | При изменении курса система спрашивает подтверждение пересчёта                                                                                                                                                                          |
| **Сумма**                         | Итог закупки в USD (сумма по колонке «Сумма закупки»)                                                                                                                                                                                   |
| **Сумма в валюте инвойса**        | Итог в валюте счёта поставщика                                                                                                                                                                                                          |
| **Сумма затрат**                  | Логистические затраты, вводимые вручную (если нет привязки через «Движение денег»)                                                                                                                                                      |
| **Наценка**                       | Режим расчёта наценки к цене инвойса                                                                                                                                                                                                    |
| **Количество поставок**           | Число вкладок-поставок (см. ниже)                                                                                                                                                                                                       |
| **Статус / Статус оплаты**        | Из регистра состояний (логистика и оплата)                                                                                                                                                                                              |
| **Номер/дата инвойса поставщика** | Реквизиты счёта поставщика                                                                                                                                                                                                              |
| **Локал**                         | Используется в отчёте `КонтрольВводаДанных`:<br>При проверке «номенклатура без веса» товары из проведённых инвойсов с `Локал = Истина` исключаются из контроля. Смысл: для «локальных» поставок вес не требуют так же, как для обычных. |

### Табличная часть «Товары» (`ВКД_Товары`)

Основная таблица позиций:

| Колонка | Описание |
|---------|----------|
| **Номенклатура** | Товар или услуга |
| **Количество** | Кол-во |
| **Цена инвойса / Сумма инвойса** | В **валюте счёта поставщика** (из инвойса закупки) |
| **Цена закупки / Сумма закупки** | В **USD** (валюта документа) |
| **Цена со скидкой / Сумма со скидкой** | При распределении скидки |
| **Наценка / Цена с наценкой** | При включённом режиме наценки |
| **НДС** | При необходимости (видимость настраивается) |

**Кнопка «Пересчитать»** пересчитывает колонки **«Цена закупки $»** и **«Сумма закупки $»** по **курсу** из шапки и значениям **«Цена инвойса»** / **«Сумма инвойса»** (см. встроенную справку документа).

### Поставки (несколько партий отгрузки)

Если товар приходит **не одной партией**, документ поддерживает **разделение по поставкам**:

1. Сначала проводится инвойс **без поставок** (или с одной).
2. После проведения логист может **добавить поставку** — появляется вкладка «Поставка 2», «Поставка 3» и т.д. (до 8).
3. На каждой вкладке указывается, **сколько единиц** каждой номенклатуры входит в эту поставку.
4. Суммы по поставкам считаются как **цена закупки × количество**.
5. При сохранении система может предложить **перенести остаток** нераспределённого товара в новую поставку.

> **Важно:** добавить поставку можно только у **проведённого** документа и если инвойс **ещё не включён в отправку**.

### Статусы логистики

Хранятся в регистре **«Состояния инвойсов»** (на форме — поле «Статус»):

| Статус | Значение |
|--------|----------|
| Не отправлен | Товар ещё не отгружен поставщиком |
| В пути | Есть документ отправки |
| Частично прибыл | Часть товара оприходована |
| Прибыл | Полностью получен |

Статус меняется документами **Отправка**, **Отправка AWB**, **Отправка перемещений**, **Приходная накладная** и др.

### Скидки и наценка

- **Скидка** — через документ-основание скидки (`ВКД_ДокументСкидки`) и флаг **«Распределить»**.
- **Наценка** — включается флагом **«Наценка»**; процент и цена с наценкой пересчитываются в строках.

### Затраты (логистика)

Затраты на инвойс попадают двумя путями:

1. **Движение денег** (вид «Логистика») с привязкой к инвойсу в табличной части «Инвойсы».
2. Поле **«Сумма затрат»** в шапке.

При проведении затраты **распределяются по товарам пропорционально весу** (нужен **вес в карточке номенклатуры**). Если вес не заполнен — выводится предупреждение.

### Оплата и привязки

Если у контрагента включено **«Привязывать инвойсы»**, на форме видна вкладка **«Привязки»** — сопоставление инвойса с платежами (`Движение денег`).

### Команды

| Команда | Действие |
|---------|----------|
| **Движение инвойсов** | Открывает форму выбора для анализа движения инвойсов по доставкам |
| **Проверка приходных** | Отчёт по приходным накладным, связанным с инвойсом |
| **Печать «Инвойс»** | Печатная форма для поставщика/внутреннего использования |

### Типовой порядок работы

1. Создать **Инвойс закупки** (данные от поставщика).
2. На его основании — **Инвойс** (вид «Товар»), проверить состав и курс, нажать **«Пересчитать»** при необходимости.
3. **Провести** документ.
4. При частичных поставках — **добавить поставки**, распределить количества, записать снова.
5. Оформить **отправку** → **приходную накладную**.
6.  Оплату отразить через **Движение денег** с привязкой к инвойсу.

### Ограничения и подсказки

- Нельзя создать второй инвойс того же **вида операции** на одно основание.
- Нельзя добавить поставку, если инвойс уже в **отправке**.
- Максимум **8 поставок** (при большем числе — обратиться к разработчику).
- Документ с **только услугами** не формирует ожидание поставки в регистре отправок.

### Реквизит «Локал»

Булев флаг (галочка) документа Инвойс. 
#### Где находится

В форме инвойса — в шапке рядом с полем Отправитель (склад-отправитель документа-основания).

Также отображается иконкой в списке инвойсов при выборе в Движение денег (оплата поставщику / логистика): у строк с включённым «Локал» показывается картинка.

#### На что влияет

1. Визуальная пометка  
    Помогает отличить локальные инвойсы от обычных при подборе к оплате.
    
2. Контроль веса номенклатуры (отчёт Контроль ввода данных)  
    Для товаров из проведённых инвойсов с флагом Локал не требуется заполнять вес (они исключаются из проверки «номенклатура без веса»).  
    Для обычных (не локальных) инвойсов при оплате/привязке контроль веса по-прежнему действует.
    

На проведение инвойса, приходные накладные, цены и долги флаг напрямую не влияет — в коде проведения инвойса он не используется.

#### Как работает

- Ставится вручную в инвойсе (автоматической установки в конфигурации нет).
- Имеет смысл для локальных закупок/поставок, где вес для распределения логистических затрат не критичен.
- Чтобы исключение по весу сработало, инвойс с «Локал» должен быть проведён.

# Часть 2. Для разработчика

### Метаданные

| Параметр | Значение |
|----------|----------|
| **Имя** | `_Инвойс` |
| **Синоним** | Инвойс |
| **Основание** | `Document.ИнвойсЗакупки` |
| **Формы** | `ФормаДокумента`, `ФормаСписка`, `ФормаВыбора`, `ФормаРазделения`, `ФормаВыбораДоставки` |
| **Макет печати** | `Templates/Инвойс` |
| **Подсистема** | Закупки |

### Реквизиты шапки (ключевые)

```
Контрагент, Валюта, Курс, КурсУстановленВручную, Сумма, СуммаВВалютеИнвойса,
ДокументОснование (→ ИнвойсЗакупки), ВидОперации (→ ВидыОперацииИнвойс),
КоличествоПоставок, СуммаЗатрат, Наценка, ТолькоУслуги, Локал,
ВКД_НомерИнвойсаПоставщика, ВКД_ДатаИнвойсаПоставщика, ВКД_Количество,
ВКД_ДокументСкидки, ВКД_Скидка, ВКД_Распределить, ...
```

### Табличные части

#### `ВКД_Товары`

Основной состав. Связь с поставками — через **`ИдСтроки`** (уникальный идентификатор строки, не путать с `НомерСтроки`).

Ключевые реквизиты: `Номенклатура`, `Количество`, `ЦенаИнвойса`, `ЦенаЗакупки`, `СуммаЗакупки`, `ЦенаСоСкидкой`, `СуммаЗакупкиСоСкидкой`, `Наценка`, `ЦенаСНаценкой`, `ИдСтроки`, `Основание`.

#### `Поставки`

Детализация по номерам поставок: `ИдСтроки`, `Номенклатура`, `Количество`, `Сумма`, `Поставка` (номер 1…N).

### Архитектура формы (`ФормаДокумента`)

Форма **сложная**, с разделением UI и данных:

| Слой | Назначение |
|------|------------|
| **`Объект.ВКД_Товары`** | Сохраняемая ТЧ документа |
| **`Объект.Поставки`** | Сохраняемая ТЧ поставок |
| **`Поставки` (реквизит формы)** | Таблица формы для отображения; заполняется процедурой `ПоставкиВФорму()` |
| **Динамические вкладки** | `ДобавитьПоставкуНаСервере()` клонирует элементы группы «Поставка 1» |

**Ключевые процедуры формы:**

| Процедура | Назначение |
|-----------|------------|
| `ПоставкиВФорму()` | Синхронизация таблицы формы с ТЧ; пересчёт сумм `ЦенаЗакупки × Количество` |
| `ПеренестиДанныеПоставкиСФормыВТЧ()` | Перед записью — перенос из формы в `Объект.Поставки` |
| `ПересчитатьЦенуИСуммуПоКурсу()` | Пересчёт USD из цены инвойса и курса |
| `ОбновитьИнвойсСкорректированный()` | Таблица «скорректированный инвойс» (остатки по поставкам) |
| `ПередЗаписью()` | Итоги, очистка «осиротевших» поставок, предложение переноса остатка |

### Модуль объекта — проведение

**Файл:** `Documents/_Инвойс/Ext/ObjectModule.bsl`

#### Проверки перед проведением

1. **Уникальность** — один проведённый `_Инvойс` на пару `(ДокументОснование, ВидОперации)`.
2. **Вес номенклатуры** — предупреждение, если есть затраты, а вес = 0.
3. `ПроверкаВозможностиПроведения()` — **пустая** (зарезервировано).

#### Движения по регистрам

| Регистр | Что пишется |
|---------|-------------|
| **`_ВзаиморасчетыСПоставщиками`** | Долг поставщику (`СуммаОплаты`), валюта — из инвойса или основания |
| **`ВКД_ОприходованиеНоменклатуры`** | Ожидаемое оприходование: по `ВКД_Товары` (1 поставка) или по `Поставки` (N поставок); стorno корректировок |
| **`СкорректированныеИнвойсы`** | Состав инвойса для контроля корректировок (`ИдСтроки`, суммы) |
| **`ОтправкаИнвойсов`** | Ожидание поставок (если не только услуги) |
| **`РасчетыПоИнвойсам`** | Если `Контрагент.ПривязыватьИнвойсы` — сумма в валюте инвойса + курс |
| **`Затраты`** (РС) | Распределение логистических затрат по весу; пересчёт в базовую валюту через `РаботаСВалютой.Пересчитать2025` |
| **`ДокументыКПроведению`** | Очистка очереди проведения для этого документа |

#### Ветвление по поставкам

```
Если Поставки.Количество() = 0 Тогда
    // Одна поставка: движения из ВКД_Товары, Поставка = 0
Иначе
    // Несколько поставок: движения из Поставки + стorno ВКД_Оприходование от КорректировкаИнвойса
КонецЕсли
```

#### Замечание по коду

После записи **`Затраты`** в модуле объекта есть **`ВОЗВРАТ`** (строка ~453) — код ниже **не выполняется** (в т.ч. незавершённая запись в `СостоянияИнвойсов`). Статусы инвойса обновляются **другими документами** через `РаботаСИнвойсами`.

### Связанные объекты

| Объект | Связь |
|--------|-------|
| `ИнвойсЗакупки` | Основание; источник валюты инвойса и номера поставщика |
| `КорректировкаИнвойса` | Корректировка состава/количеств; storno в `ВКД_ОприходованиеНоменклатуры` |
| `ДвижениеДенег` | Оплата, логистика (`Инвойсы.Инвойс`) |
| `Отправка`, `ОтправкаAWB`, `ОтправкаПеремещений` | Меняют `СостоянияИнвойсов`, `ОтправкаИнвойсов` |
| `ПриходнаяНакладная` | Оприходование; партия ссылается на `_Инвойс` |
| `РасходнаяНакладная` | Может создаваться на основании `_Инвойс` (если `Проформа = Инвойс`) — legacy-сценарий |
